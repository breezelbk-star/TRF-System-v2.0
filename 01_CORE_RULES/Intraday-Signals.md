📌 TRF盘中行为识别 + 离场纪律（核心精简版）

一、盘口级别（分钟级判断）

1. 放量下跌（核心信号）
→ 5分钟/15分钟突然放量长阴
→ 无明显承接（无快速收回）

结论：
= 主力主动卖出
= 不是洗盘，是出货

操作：
→ 直接减仓 / 清仓
→ 不做等待幻想


2. 反弹无量（弱势确认）

表现：
→ 下跌后反弹
→ 成交量明显萎缩
→ 无法突破均线（MA10/MA20）

结论：
= 无增量资金
= 只是技术性反弹

操作：
→ 反弹就是卖点
→ 不做加仓


3. 冲高回落（分歧信号）

表现：
→ 快速拉升
→ 无法封板 / 无持续性
→ 回落速度快

结论：
= 资金分歧
= 高位不稳

操作：
→ 逢高减仓
→ 不追涨


━━━━━━━━━━━━━━━

二、日K级别（趋势判断）

1. 巨量涨停打开（最关键）

表现：
→ 成交量放大2倍以上
→ 涨停被打开
→ 留长上影线
→ 未站稳关键均线（MA10）

本质：
= 高位换手 + 主力派发

操作纪律：
→ 当天至少卖出50%
→ 不再加仓


2. 次日阴线（确认转弱）

表现：
→ 大阴线
→ 跌回均线（MA20/MA30）

结论：
= 突破失败

操作：
→ 剩余仓位清掉


3. 反弹不过MA10（趋势反转）

表现：
→ 反弹触碰MA10后回落

结论：
= 短趋势结束

操作：
→ 必须离场


4. 跌破MA30 + 放量

表现：
→ 放量阴线跌破MA30

结论：
= 主升行情结束
= 进入下跌结构

操作：
→ 禁止抄底
→ 等新结构


━━━━━━━━━━━━━━━

三、核心交易原则（必须执行）

1. 量 > 价
→ 放量下跌优先级最高

2. 先卖再判断
→ 不做情绪交易

3. 反弹不是机会，是退出机会
→ 弱势市场尤其重要

4. 赚钱靠节奏，不靠扛单
→ 快进快出优先


━━━━━━━━━━━━━━━

四、一句话总结（交易口诀）

巨量开板先减仓  
次日转弱要清仓  
反弹不过十日线  
跌破三十别幻想
