# TRF-Tech-Scanner v2.0 · 通达信指标组说明（A + B + C）

> 适用环境：通达信（盘后/盘中均可用，推荐盘后日线级扫描）  
> 适用账户：TRF v2.0 科技成长主线账户（半导体 / AI 服务器 / 信创安全计算）  
> 模块组成：  
> - A：突破加速（Accel）  
> - B：二波反包（Rebound）  
> - C：假突破过滤（FakeBreak）

---

## 0. 总体设计思路

这套扫描器是给 **Jimmy 的 TRF v2.0** 配套的技术选股工具，目标很简单：

1. **A 模块**：帮你找出类似 **侨源 / 南大光电** 这种  
   >「趋势多头 + 接近高点 + 放量加速」  
   的 **第一波突破股**。

2. **B 模块**：帮你找出类似 **北方华创 11 月 24 日 那根“二波反包大阳”** 的  
   >「已经走出第一波 → 回踩确认 → 再次放量反包」  
   的 **第二波反包 / 再起势龙头**。

3. **C 模块**：专门用来识别、标记类似 **中科星图假突破那种“高位放量长上影”** 的  
   >「高位冲高回落 + 放量 + 上影长」  
   的 **假突破 K 线**，用作 **过滤 / 降权**。

## 1. 模块 A：TRF-A-Accel-V2.0（突破加速 · 侨源 / 南大光电型）

**文件建议：** `/indicators/TRF-A-Accel-V2.0.tn6`  

### 1.1 核心逻辑

- **趋势前提**：  
  - 股价站在 MA60 之上，且 MA20 > MA60  
  - 即：**中期多头结构成立**

- **斜率结构**：  
  - MA5 > MA10 > MA20  
  - 典型 **右侧多头斜率**，侨源 / 南大光电那种顺滑抬升形态

- **接近突破**：  
  - 收盘价 ≥ 最近 20 日最高价的 97%  
  - 意味着已经站在“一眼就要突破”的位置，而不是盘中随意一根涨幅

- **量能结构**：  
  - 脉冲型（PULSE）：  
    - 今日成交量 ≥ 5 日均量 1.7 倍  
    - 今日成交额 ≥ 5 日均额 1.6 倍  
  - 堆量型（STACK）：  
    - 量能、金额的 5 日均线都向上、且今日 > 均线  
  - 两者任一成立，即视为 **加速资金入场**

- **情绪控制**：  
  - 类似 KDJ.K＜90 的“不过热限制”  
  - 避免极端情绪顶部

- **K 线形态**：  
  - 阳线收盘  
  - 上影线 < 3.5%（避免假突破长上影）

- **基础过滤**：  
  - 价格 > 5 元  
  - 成交额 > 2 亿（过滤冷门票）

### 1.2 它帮你抓谁？

- 侨源科技（QYA）  
- 南大光电这类 **“第一次放量突破 + 结构漂亮”** 的票  
- 即：**模式① + 模式③ 的结合体：突破加速 + 主升段初期**

### 1.3 推荐用法

- **使用频率**：  
  - 每日收盘后跑一次（日线）  
- **用途**：  
  - 作为第二天的 **进攻候选池**  
  - 所有结果交给 TRF 核心（Trend/Rotation/Flow/Risk）做二次判断  
- **注意**：  
  - A 模块只负责“技术形态 + 量能”维度，不考虑政策 / 板块，这部分交给 TRF 主线判断。

## 2. 模块 B：TRF-B-Rebound-V2.0（二波反包 · 北方华创型）

**文件建议：** `/indicators/TRF-B-Rebound-V2.0.tn6`  

> 目标：专门抓 **北方华创 2025-11-24 那根“站回多根均线的二波反包大阳”** 一类的结构。

### 2.1 核心逻辑（简要）

- **第一波确认（FIRSTWAVE）**  
  - MA10 > MA20 > MA60  
  - 过去 20 日涨幅 > 8%  
  - 说明：这票已经走出过 **第一段主升浪**，不是从“地板”突然起飞的妖股。

- **回调逻辑（PULLBACK）**  
  - 中间必须有一段 **真·回调 / 调整**  
  - 避免“直线上天”式的不可持续走法

- **二波反包（REBOUND）**  
  - 当前 K 线涨幅 ≥ 3%  
  - 收盘价 ≥ 最近几日收盘价高位的 96%以上  
  - 同时站回 10 日、20 日线  
  - 对齐：北方华创 11 月 24 日那根“**一根大阳重新站回均线系统**”

- **量能确认（VOLOK）**  
  - 今日量能 / 金额 ≥ 近 5 日均量 / 均额 1.4–1.5 倍  
  - 表示“**二波是有真金白银推的**”，不是空心阳线

- **K 线尽量是真阳（STRONGCANDLE）**  
  - 阳线实体足够  
  - 上影不极端  
  - 排除“针刺型假反包”

- **风险过滤**  
  - 避免过热（K 值过高）  
  - 价格区间合理  
  - 成交额 ≥ 2 亿

### 2.2 它帮你抓谁？

- 北方华创那种：  
  - **第一波已经走过 → 中间整理 / 回踩 → 再来一根确认二波的大阳线**  
- 各类半导体/光模块/AI 服务器龙头股的二波再启

### 2.3 推荐用法

- **使用频率**：  
  - 每日收盘后跑一次（日线）  
- **用途**：  
  - 给你一个“**可以考虑二波/再起势重仓的龙头名单**”  
- **配合方式**：  
  - 与 A 模块不同：  
    - A = 抓“第一次突破的进攻票”  
    - B = 抓“已经证明自己、准备走第二段的龙头”

## 3. 模块 C：TRF-C-FakeBreak-V2.0（假突破过滤 · 星图型）

**文件建议：** `/indicators/TRF-C-FakeBreak-V2.0.tn6`  

> 目标：专门识别 **“高位放量长上影 + 实体不强”** 的假突破，  
> 典型代表：**中科星图那类“冲高回落假动作”**。

### 3.1 核心逻辑

- **位置条件（HIGHZONE）**  
  - 收盘价 ≥ 近 20 日最高价的 95%  
  - 即：在明显的 **阶段高位区域** 发生

- **量能条件（VOLPULSE）**  
  - 今日成交量 / 金额 ≥ 5 日均值的 1.8 倍  
  - 有明显资金“推”了一把

- **K 线结构**  
  - 明显长上影：上影 ≥ 3.5%  
  - 实体不强：  
    - 涨幅 ≤ 2%  
    - 或 收在当日高低价中轴线以下  
  - 综合意思：  
    > 冲得很高，但收盘“力竭”，大概率是出货 / 诱多

- **基础过滤**  
  - 价格 5–200 元  
  - 成交额 ≥ 1.5 亿

### 3.2 推荐用法（怎么配合 A / B）

逻辑不需要复杂：

1. **先跑 A 模块 + B 模块** → 得到 **“候选强势股池”**  
2. 再用 **C 模块** 扫描这批票，如果某票在 C 中也被命中：  
   - 给它打上：**“FakeBreak 假突破标记”**  
   - 这票：
     - 不做追高  
     - 不在当日 / 次日做加仓  
     - 仅保留底仓等待确认，或者直接放弃

> 简单说：  
> - **A、B 模块是“抓机会”**  
> - **C 模块是“帮你避坑”**

## 4. 推荐日常流程（盘后版本）

> 你说过：指标主要是 **盘后使用**，作为第二天 TRF 策略的输入。可以按下面节奏来：

1. **收盘后**  
   - 跑一遍 **A 模块（Accel）**  
   - 跑一遍 **B 模块（Rebound）**  
   - 合并结果 → 得到一份 **“技术形态候选名单”**

2. **对合并名单，用 C 模块（FakeBreak）检查**  
   - 被 C 模块命中的 → 标记为 **“假突破 / 高危 K 线”**  
   - 在 TRF 策略中 **降权 / 不当日参与 / 不追高**

3. **把最终名单发给我（截图 or 股票代码列表）**  
   - 我根据 TRF v2.0：  
     - Risk（环境 & 仓位）  
     - Trend（大盘 & 板块 & 个股）  
     - Rotation（主线/分支轮动）  
     - Flow（日线量能 & 分时窗口）  
     - My-Style-Model（成功/失败模式）  
   → 给你 **评分 + 排序 + 身份标签（Core/AR/AC/Test/Side/Risk）**  
   → 并接入第二天的 Morning-Playbook / Night-Playbook。
