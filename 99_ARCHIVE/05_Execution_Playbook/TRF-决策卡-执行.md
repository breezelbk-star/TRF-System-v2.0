# TRF 日内执行卡（Execution Card）

适用模型：
- TRF-T（趋势股 10%–25%）
- TRF-A（侨源型 主升浪）

==================================================
【一】盘前 5 分钟（是否有资格看这只票）
==================================================

必须全部满足，否则直接忽略：

[ ] 股价在 MA30 之上
[ ] MA30 走平或向上
[ ] 近 1–3 个月出现 ≥20% 主升
[ ] 当前回撤 10%–25%
[ ] 回撤期无连续放量长阴

→ 不满足 = 今天与我无关

==================================================
【二】模型判断（只选一个）
==================================================

慢、稳、磨 → TRF-T  
快、猛、狠 → TRF-A  

⚠ 禁止同一只股票来回切模型

==================================================
【三】盘中买点许可（出现才允许动手）
==================================================

▶ TRF-T（趋势模型）买点

A 类（优先）：
[ ] 放量阳线站上 MA10
[ ] 回踩 MA20/30 后放量反包

B 类（次优）：
[ ] 横盘 ≥5 天
[ ] 放量突破横盘上沿

→ 初始仓位：40%–60%

--------------------------------------------------

▶ TRF-A（侨源型）买点

[ ] 长期横盘后爆量点火
[ ] 分时极强，回踩极浅
[ ] 市值 50–200 亿

→ 仓位集中，但必须分批

==================================================
【四】加仓规则（极其重要）
==================================================

允许加仓的前提（必须全部满足）：

[ ] 当前仓位浮盈 ≥ +5%
[ ] 未跌破 MA20 / MA30
[ ] 大盘未系统性转弱

加仓方式：
- 突破前高：+20%~30%
- 回踩确认：+10%~20%

✖ 禁止浮亏加仓  
✖ 禁止“感觉还能涨”加仓  

==================================================
【五】减仓 / 止损纪律（无条件执行）
==================================================

▶ TRF-T（趋势）

- 跌破 MA30 → 清仓
- +10%：减 1/3
- +15%：再减 1/3
- +20%~25%：清仓

▶ TRF-A（侨源型）

- 放量滞涨：减 1/3
- 跌破 5/10MA：继续减
- 情绪退潮：只减不加

==================================================
【六】盘中否决条件（看到立刻停手）
==================================================

✖ 指数破位
✖ 放量冲高回落
✖ 分时高点下移
✖ 情绪股、消息股
✖ 临盘改变计划

==================================================
【七】一句话铁律
==================================================

不预测  
不抄底  
不幻想  

只执行  
只复利  
只做对的那一段
