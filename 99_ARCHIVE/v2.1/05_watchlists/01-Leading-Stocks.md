# TRF v2.1 强势股观察池（Leading Stocks Watchlist）

目的：  
建立一个动态更新的“强势股池”，反映当前主线、龙头、潜在爆发点。

---

# 📌 A 类（主线绝对强势股）
符合条件：
- 行业主线（半导体 / 光刻 / AI 服务器）
- 强趋势评分 ≥ 80
- 弹性评分 ≥ 70
- 资金流持续正向

示例（按行业分类）：

## 半导体设备：
- 北方华创（趋势龙头）
- 中微公司（设备核心）
- 长光华芯（弹性龙头）
- 华海清科（次龙头 → 二波潜力）

## 光刻材料 / 先进封装：
- 南大光电
- 安集科技
- 芯源微

## AI 服务器 / 安全算力：
- 中科曙光
- 景嘉微
- 工业富联（大票趋势良好）

---

# 📌 B 类（强趋势 + 有可能晋升为龙头）
条件：
- 趋势评分 70–80
- 行业热度靠前
- 有突破结构，但未进入主升浪

示例：
- 金道科技（爆发分支，但非行业龙头）
- 扬杰科技
- 博通集成
- 国科微（右侧趋势良好）
- 全志科技

---

# 📌 C 类（潜在爆发点 / 反转结构）
条件：
- MACD 零轴下金叉
- 平台 ≥ 30 日
- 行业正处上升周期

示例：
- 芯原股份
- 兆易创新
- 瑞芯微
- 卓胜微

---

# 📌 D 类（观察但暂不参与）
- 型态不稳定
- 行业非主线
- 量价矛盾

示例：
- 大消费类
- 房地产链条
- 医药非热门分支

---

# 📌 动态更新机制
每天收盘后更新以下内容：
1. 强势股加入 A 类  
2. 二线趋势股加入 B 类  
3. 底部改善加入 C 类  
4. 破位股移出列表  

此列表是 **侨源 → 接力股** 的最重要参考工具。
