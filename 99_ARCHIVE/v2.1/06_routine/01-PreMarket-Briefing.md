# TRF v2.1 盘前检查（Pre-Market Briefing）

每日 09:15–09:25 固定流程  
目标：判断今天应使用的“战术模式”（攻击 / 防守 / 观察）

---

# ① 大盘结构检查（必做）
- 上证指数是否站上 MA20？
- 创业板是否处于趋势向上？
- 半导体 ETF 是否连续两天净流入？
- 北向资金方向是否偏多？

➡ 结论：
- 全部满足 → 攻击模式（提高仓位）
- 满足 2 项 → 中性模式（保持仓位）
- ≤1 项满足 → 防守模式（低仓+不追涨）

---

3. 电力 / 电网安全  
4. 低空经济 / 机械制造

- 行业热力图
- 板块前 3 分钟涨幅
- 龙头结构强度（昨晚是否强势）
