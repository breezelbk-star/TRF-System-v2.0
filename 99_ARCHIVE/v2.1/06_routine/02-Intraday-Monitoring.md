# TRF v2.1 盘中监控（Intraday Monitoring）

盘中任务分为三个时间段：  
09:30–10:00  
10:00–13:30  
13:30–15:00  

---

# ① 09:30–10:00（最关键的强弱判断窗口）

检查：
1. 今日主线板块是否被确认？  
2. 龙头是否出现？是否封板有力？  
3. 核心标的是否强过指数？  
4. 半小时成交额是否放大？  

盘中操作：
- 若强势 → 立即执行“趋势加仓 / 龙头买点”  
- 若弱势 → 暂不加仓，观察结构  

---

# ② 10:00–13:30（趋势判断区）

观察：
- 趋势股是否沿 5 分钟趋势上行？  
- 龙头是否出现分歧？（分歧是二波起点）  
- 板块内部是否扩散？  

操作：
- 分歧后回流 → 龙头二波最佳买点  
- 强趋势回踩 → MA10 低吸  
- 若出现反转大阴线 → 减仓防守  

检查看以下五个信号：

① 放量突破 → 加仓  
② 缩量回踩 → 低吸  
③ 长上影 → 减仓  
④ 板块转弱 → 暂停交易  
⑤ 龙头断板 → 立即降仓  

---

# ③ 13:30–15:00（方向确认+卖点捕捉）

重点检查：
- 是否进入加速阶段？  
- 是否出现背离？  
- 是否出现资金出逃迹象？  

T+0 注意：
- 午后急杀 = 做低吸 T  
- 午后急拉 = 做高抛 T  

尾盘策略：
- 若强势板块 → 尾盘可加仓（尤其突破票）  
- 若出现放量大阴 → 尾盘减仓或清仓
