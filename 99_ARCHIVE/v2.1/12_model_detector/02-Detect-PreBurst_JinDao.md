# TRF 模型检测器：起爆前夜模型（JinDao_Like Detector）
版本：TRF v2.1

用于识别某支股票是否处于“主升浪第一波 → 第二波启动前”的结构（如金道科技）。

---

# 1. 模型特征（必须满足 5 项中 ≥3 项）
## （1）首次突破前平台
- 有明显平台（15–30 天）
- 放量突破，但未出现情绪加速

## （2）突破后进入洗盘期
出现：
- 假阴真阳  
- 小实体 K  
- 换手下降  
- 缩量回踩不破支撑

## （3）控盘特征明显
- 上影线多  
- 实体小但收盘强势  
- 趋势不破

## （4）板块处于轮动加强期
- 半导体设备  
- 资金连续两日净流入  
- 行业内有龙头（如长光）带动

## （5）突破结构完好
- MA10 > MA20  
- 回踩不破 MA20  
- 量价未出现衰竭信号

---

# 2. 判定逻辑（TRF 自动识别）

```
IF (突破平台=True) AND (缩量洗盘=True) THEN
    IF (控盘结构=True) OR (板块走强=True) THEN
        判定 = "金道科技模式（起爆前夜结构）"
```

---

# 3. 输出示例
```
股票B 出现金道模型：突破 + 洗盘 + 板块强化  
→ 建议作为“主升浪候选”重点跟踪
```
