# TRF v2.1 接力路径模型（Relay Path Model）
版本：TRF v2.1

该模型用于判断：  
当主线板块启动后，龙头股之间是如何“接力”的？  
侨源 → 金道科技 → 长光华芯  
为什么它们能串成一条“趋势链”？

----

# 一、什么是接力路径（Relay Path）？
接力路径 = 在同一主线上，不同级别强势股之间的 **资金传递路线**。

主线强 → 龙头强  
龙头强 → 二龙、三龙启动  
主升浪 → 后排跟涨  

典型特征：
- 龙头先发  
- 二排补涨  
- 强票之间“用情绪传递趋势”

侨源 → 金道科技 → 长光华芯  
正是这种路径的典型案例。

----

# 二、接力顺序的三个阶段

## **阶段 1：主线初启动（侨源阶段）**
标志：
- 主线资金首次活跃  
- 成交放大  
- 龙头未确定

侨源的作用：
- 代表“最先反应资金”的一批强势票  
- 但不一定是最终龙头  
- 提供趋势信号（Trend Signal）

侨源 = “主升浪第一节拍的点火者”

---

## **阶段 2：主线趋势确立（接棒者：金道科技）**
标志：
- 资金确认主线有效  
- 细分领域开始强化  
- 龙头位置逐渐上移

金道科技的作用：
- 接到侨源的火炬  
- 市场开始聚焦“半导体设备”  
- 主线方向由“发散”→“收敛”

金道科技 = “趋势接棒者”
（趋势最健康、结构最清晰的一档）

---

## **阶段 3：主线爆发（长光华芯成为龙头）**
标志：
- 市场一致性最强  
- 全市场主线确认  
- 龙头加速、换手极高

长光华芯作用：
- 执行最终龙头角色  
- 进入主升浪加速段（第三阶段）
- 情绪达到全场最强

长光华芯 = “终极龙头”

---

# 三、接力模型为何成立？（TRF 三因子解释）

## ① Trend（趋势因子）
趋势强化顺序为：

侨源（最先启动趋势）  
→ 金道科技（趋势结构最漂亮）  
→ 长光华芯（趋势进入加速）

## ② Rotation（轮动因子）
资金从：

分散投机  
→ 聚焦半导体设备  
→ 集中到龙头（长光）

## ③ Flow（资金流因子）
资金行为路径：
- 侨源：情绪流  
- 金道：技术流（控盘类）  
- 长光：机构 + 大资金主导流

这正是 A 股龙头运行的基本定律。

---

# 四、最重要的部分：如何提前找到下一棒？

这是模型的核心价值。

## ⭐ 判断“下一棒”必须满足三条：

### **条件 1：同板块 or 子链条强化（半导体设备链当中）**
接力必须发生在：

- 光刻胶
- 清洗设备
- 刻蚀设备
- 先进封测
- 精密运动组件（如金道）

这是长光爆发前几天，资金已经在做的事。

---

### **条件 2：结构必须比侨源更强、比金道更整齐**
趋势结构分三档：

- 侨源 = 初段（混乱 → 启动）  
- 金道 = 明确趋势（理想转折）  
- 长光 = 主升浪（喷发结构）  

下一棒必须：
> “处于启动 → 主升浪之间的过渡点”

---

### **条件 3：换手必须准备好爆发（>12%）**
没有换手 → 不可能接力  
换手太高（>25%） → 进入尾声  

最佳区间：**12–18%**

---

# 五、如何实战判断“下一棒”？（具体标准）

满足以下 4 项即可定义为“接力候选”：

### ✔ ① 板块强于指数（三日强度）
### ✔ ② 股票突破 3 周平台
### ✔ ③ 换手 12–18%
### ✔ ④ 资金未出现流出（连续两日净流入）

当 4 项同时满足：

> → **这是“金道接力模型”**  
> → 可能成为下一支强势票  
> → 进入你的“主升候选池”  

未来系统将自动识别。

---

# 六、三大样本如何贯通成一条路径？

| 股票 | 角色 | 接力意义 |
|------|------|-----------|
| 侨源 | 点火者 | 告诉你主线来了 |
| 金道科技 | 接棒者 | 主线趋势强化、结构最强 |
| 长光华芯 | 龙头 | 主升浪爆发确认 |

这就是为什么：

**侨源之后 → 最值得关注的是金道科技  
金道科技之后 → 轮动最可能推向长光华芯这种级别**

---

# 七、未来主线接力预测（模型应用）

当前路径显示：  
→ 主升浪资金会优先继续集中在：  
**半导体设备 → 光刻胶 → 精密组件 → EDA → 材料链**

其中最可能成为下一棒的方向：

1. **金道科技继续上攻（主升2浪 → 3浪）**  
2. 半导体设备内的第二梯队（南大光电、明微电子等）  
3. 长光华芯回踩后的第二轮主升浪  

---

# 八、总结：接力路径模型的价值

- 让你**提前知道下一棒在哪**  
- 不再随机选股，而是选“接力成功概率最高”的  
- 让你的交易进入节奏，而不是追涨杀跌  
- 让 TRF v2.1 具备“趋势链识别能力”  

**侨源 → 金道科技 → 长光华芯  
这条接力链不是巧合，是市场逻辑。**
