# 📈 TRF 投资系统 v2.0（科技主线版）
> Trend + Rotation + Flow  
> 半导体 / AI 服务器 / 信创安全计算 为核心的主动交易系统  
> 结合三色风险灯（Risk-Light）+ 执行系统（Execution）+ 交易人格模型（My-Style）  
> 用于实现 **高胜率、低回撤、强纪律性** 的实盘体系。

---

# 🚀 系统目标（System Mission）
TRF v2.0 的目标不是预测市场，而是：

- 构建 **稳定且可复用** 的交易框架  
- 从强主线中捕捉 **主升浪行情**  
- 通过风险灯系统控制回撤  
- 让每日实盘分析具备 **一致性与稳定性**  
- 让 AI 能够基于固定规则 + 实时截图 输出最优策略

系统包含两层：

### ✔ 内核层（不会轻易修改）  
存放 Trend / Rotation / Flow / Risk / Execution / My-Style 消费规则

### ✔ 应用层（可随时扩展）  
每日操作流程 / 关键位模板 / 策略评分模型 / 案例库

# 🔧 核心功能模块介绍

## 1️⃣ Trend（趋势系统）
- 判断大盘趋势（MA20 / MA60）
- 判断主线趋势（半导体 / AI / 信创等）
- 判断个股趋势（多头结构/弱势结构）
- 决定市场环境是 **偏多 / 震荡 / 防守**

➡ 文件：`TRF-Core/1.1-Trend.md`

---

## 2️⃣ Rotation（轮动系统）
- 科技成长固定主线（半导体 / AI 服务器 / 信创 等）
- 可变风口主线（如卫星、工控、机器人）
- 账户四类角色（Core / Attack / Defensive / Test）
- 主线内部高低切换
- 二线补涨 / 龙头滞涨切换策略

➡ 文件：`TRF-Core/1.2-Rotation.md`

---

## 3️⃣ Flow（资金系统）
- 放量突破 / 放量派发
- 缩量洗盘 / 缩量走弱
- 换手率判断
- 主线与分支同步性判断

➡ 文件：`TRF-Core/1.3-Flow.md`

---

## 4️⃣ Risk（三色风险灯）
- 🟩 Green → 允许进攻  
- 🟨 Yellow → 谨慎低吸  
- 🟥 Red → 必须防御  
- 单票风险控制（5–10%）  
- 止盈 / 止损系统  
- 回撤管理  
- 极端行情保护  

➡ 文件：`TRF-Core/1.4-Risk.md`

---

## 5️⃣ Execution（执行系统）
- 身份标签机制（Core/Attack/Defensive/Test）
- 每日执行节奏  
  - 盘前  
  - 10:00  
  - 11:30  
  - 13:45  
  - 收盘  
- 如何加仓 / 减仓 / 换仓  
- 如何处理突破 / 假突破 / 洗盘

➡ 文件：`TRF-Core/1.5-Execution.md`

---

## 6️⃣ My-Style-Model（你的真实交易风格）
AI 在决策时必须严格遵守你的交易风格：

- 偏进攻  
- 偏好科技成长主线  
- 偏好突破 + 放量  
- 三大成功模式  
- 五大失败模式（含中国长城案例）  
- AI 协作规范（盘前/盘中/盘后）

➡ 文件：`Models/My-Style-Model.md`

---

## 7️⃣ Cases（案例库）
包含你真实操作中的：

- 成功案例（北方稀土 / 阳光电源 / 侨源）
- 失败案例（中国长城）
- TRF 如何识别主线、捕捉主升浪、避免错误

➡ 文件夹：`Cases/`

# 📘 使用方法（How to Use）

### ✔ 你不需要修改内核（TRF-Core）  
这些文件是你的“交易规则”，不会频繁改动。

### ✔ AI 每日根据截图动态输出  
你只需：

1. 盘前给：  
   - 持仓截图  
   - 指数截图  
   - GPT 选股截图  
2. 盘中给分时图  
3. 收盘给持仓截图  

AI 会自动根据 TRF 系统输出当日策略。

### ✔ GitHub 存放的是“永不变的规则”  
聊天窗口生成的是“每天变的数据”。
