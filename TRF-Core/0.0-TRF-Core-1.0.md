# TRF-System-v2.0 Core Index（内核总目录）

本目录文件只做一件事：说明 TRF 内核的整体结构，并指向具体章节文件。  
所有正式规则与细节，请以各自的 `1.x-*.md` 文件为准。

---

## 1. TRF 三大内核

> TRF = Trend（趋势） + Rotation（轮动） + Flow（资金）

- **1.1-Trend.md**  
  定义大盘趋势、板块趋势、个股趋势的判断标准，以及什么情况下属于「多头环境 / 震荡环境 / 防守环境」。

- **1.2-Rotation.md**  
  定义主线/子主线的切换逻辑、账户内部角色分层（龙头仓 / 进攻仓 / 防御仓 / 试错仓），以及高低切换的原则。

- **1.3-Flow.md**  
  定义量价关系、换手率、资金净流的基本解读方式，用于辅助判断趋势是否健康。

- **1.4-Risk.md**  
  定义三色风险灯（Green / Yellow / Red）、单票风险控制、止盈止损、回撤管理、极端行情保护等规则。

- **1.5-Execution.md**  
  汇总实盘执行层面的总规则，包括：
  - 股票角色分类与仓位上限  
  - 多周期框架（日线为主，分钟级为辅）  
  - 通用交易规则（入场 / 加仓 / 减仓 / 止损）  
  - 关键位体系（与 Key-Levels-Template 联动）  
  - 每日流程骨架（盘前 / 盘中 / 盘后）  
  - 禁止行为清单与后续扩展方向

这些属于「应用层」，会在 `docs/` 目录中逐步完善：

- `docs/00_environment_rules.md`

- `docs/Daily-Playbook.md`（预留）  
  详细描述你每天盘前、盘中、盘后的操作流程模板。

- `docs/Key-Levels-Template.md`（预留）  
  用于记录每只重点个股的支撑位、防守位、攻击位、止盈区间等。

- `docs/Stock-Rating-Model.md`（预留）  
  用于给策略选股或持仓股票打分，帮助你在换股时做比较。
