# 0. TRF v2.0 内核概览
TRF = **Trend（趋势） + Rotation（轮动） + Flow（资金）**  
并由 **Risk（三色风险灯）** 与 **Execution（执行系统）** 共同构成。

整个系统的核心目标：

- 建立 **稳定、可复用、非情绪化** 的交易体系  
- 所有每日盘前 / 盘中 / 盘后决策  
  都由本内核 + 你的截图 → ChatGPT 动态计算  
- GitHub 内核只保存不会频繁变化的“规则部分”

# 1. TRF 三大内核（核心规则层）
以下文件位于：  
`TRF-Core/`

---

## **1.1-Trend.md（趋势系统）**
定义：
- 大盘趋势：多头 / 震荡 / 防守  
- 主线趋势：半导体 / AI / 信创等方向是否成立  
- 个股趋势：结构是否健康  
  
并明确三色灯的趋势触发条件。

---

## **1.2-Rotation.md（轮动系统）**
定义：
- 科技成长主线池（长期）  
- 可变风口主线池（短期）  
- 账户四类角色（Core / Attack / Defensive / Test）  
- 主线内部的高低切换机制  
- 轮动触发信号（ETF 放量、二线补涨、策略池一致性等）

这是系统的“方向核心”。

---

## **1.3-Flow.md（资金系统）**
定义：
- 放量健康 vs 放量派发  
- 缩量洗盘 vs 缩量走弱  
- 换手率判断  
- 主线与分支的资金同步性  
- 资金形态与趋势配合的强弱判断  

主要用于鉴别“真假突破 / 真假主升浪”。

---

## **1.4-Risk.md（三色风险灯 + 风控系统）**
内容包含：
- 🟩 绿灯：允许进攻  
- 🟨 黄灯：谨慎低吸  
- 🟥 红灯：必须防御  
- 单票风险控制（5–10% 区间）  
- 止盈 / 止损系统  
- 总回撤控制  
- 极端行情保护机制  
- 行为限制（禁止追高、禁止越跌越补等）

这是系统的“刹车”。

---

## **1.5-Execution.md（执行节奏系统）**
内容包含：
- 身份标签机制（Core / Attack / Defensive / Test）  
- 盘前 → 10:00 → 11:30 → 13:45 → 收盘 的五段执行流程  
- 绿灯 / 黄灯 / 红灯 三条件驱动的行动差异  
- 每日盘前检查规则  
- 分时判断规则  
- 尾盘动作规则  
- 每日“操作地图”模板  

这是系统的“驾驶方法”。

## **My-Style-Model.md（你的真实交易风格模型）**
定义：
- 你的交易性格（偏进攻、科技主线、喜欢突破）  
- 你的三大成功模式  
- 你的失败模式（如中国长城）  
- AI 必须的协作行为（盘前/盘中/盘后）  
- 风险提前提醒机制  
- 第一原则：抓主线、抓突破、抓主升浪，不越跌越补

这是系统的“人格核心”，也是 AI 如何理解你的基础。

# 5. 文件修改原则
- **内核文件（1.x）** 几乎不改，只在版本大升级时改  
- **应用层文件（docs/）** 按需求动态扩展  
- **案例库（Cases/）** 可随时新增  
- **My-Style-Model** 按你风格改变升级为 v1.2 / v1.3

核心原则：
> GitHub 存放“不会变的规则”，  
> ChatGPT 根据截图实时输出“每天都要变的点位”。
