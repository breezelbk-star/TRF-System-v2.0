# 1.2 Rotation — 板块轮动系统（TRF v2.0 最终版）

轮动（Rotation）是 TRF 的第二核心：  
**不是换股，而是把仓位移动到“最强资金方向”。**

主线永远不是主观决定，而是由 **政策 + 资金 + 趋势** 三者共同决定。

> 系统内部统一使用四大角色：  
> **Core / Attack / Defensive / Test**  
> - My-Style-Model 中的 AR（二线补涨）和 AC（加速突破）属于 Attack 的子类型  
> - Risk / Side 属于“警告标签”，不视为角色  

---

# ✔ 1. 主线判定（Market Leadership）

TRF 系统长期围绕 **科技成长方向** 构建。  
主线必须来自以下两类：

---

## **A. 长期科技主线（固定主线池）**
永远具有长期逻辑，可随时成为主线：

- 半导体（设备 / 材料 / 设计 / 封测）
- AI 服务器 / GPU / HBM / 存储
- 算力基础设施 / 数据中心
- 信创 / 安全计算 / 工控系统
- 军工电子 / 卫星互联网
- 智能驾驶 / 机器人

这些方向 **不随行情删除**，是 TRF 系统的母方向。

---

## **B. 短期科技风口（可变主线池）**

由以下信号触发：

- 某科技子分支连续 **3 日资金净流入**  
- 板块 ETF 放量突破 MA20  
- 策略选股池连续两天出现同类股票  
- 政策催化：AI 安全 / 国资改革 / 数据要素等  
- 盘中 10:30 或 13:45 出现分支加速

这些方向属于 **短期主线**，可以参与轮动。

---

# ✔ 2. 账户角色体系（仓位结构）

账户所有持仓必须被定义为以下四类角色之一：

---

## **2.1 Core — 核心龙头仓**
- 主线方向中最强、最纯正的龙头  
- 趋势稳定、确定性高  

例如：  
NAURA、北方华创、寒武纪、中科曙光  

**仓位上限：20%–40%**

用途：吃主升浪、提供账户稳定性。

---

## **2.2 Attack — 进攻轮动仓（含 AR / AC）**
用于捕捉主线内部的 **下一棒**：

### Attack-AR（二线补涨）
- 龙头走第一波  
- 二线材料 / 零部件 / 卫星 / 工控补涨  
- 你捕捉侨源、川仪、中科星图时的盈利逻辑  
- 这是你最强模式  

### Attack-AC（突破加速）
- 突破前高  
- 盘中 10:30 / 13:45 出现二次放量  
- 这是你的第三成功模式  

**仓位上限：10%–25%**

用途：提高收益斜率。

---

## **2.3 Defensive — 防御仓**
在黄灯/红灯时启用：

- 高股息（仅在系统性弱周期）  
- 电力 / 运营商  
- 策略稳定、波动低  

**仓位：0–30%**

用途：降低波动，维持稳定。

---

## **2.4 Test — 试错仓**
- STR 选股池出现的新热点  
- 小仓试逻辑（3–5%）  
- 成功 → 进入 Attack  
- 失败 → 快速清仓  

**仓位：<5%**

用途：提前捕捉可能成为主线的方向。

---

# ✔ 3. TRF 轮动原则（执行逻辑）

## **原则 1：轮动只在科技主线内部进行**
示例：
- 半导体 → 材料 → 设计 → 设备  
- AI → GPU → 存储 → 电源管理  
- 信创 → 软件 → 服务器 → 安全计算

❌ 不会从半导体切到煤炭  
❌ 不会从 AI 切到医药  

---

## **原则 2：强者恒强 + 低位补涨**
- 主升浪 → 抓最强  
- 次日补涨 → 抓低位启动  
- 首阳 + 放量 → 最优结构  
- 龙头滞涨 → 分仓到下一棒  

---

## **原则 3：龙头震荡 → 分支突破 → 立即切**
这是你擅长捕捉侨源/川仪的核心逻辑：

- 龙头横盘  
- 二线材料 / 卫星 / 工控出现第一根强趋势阳线  
- → 改变仓位重心，而不是清核心  

---

# ✔ 4. 轮动触发信号（Rotation Trigger）

满足任意两条即成立轮动：

- 板块 ETF 放量突破 MA20  
- 板块指数放量 ≥ 1.7 倍  
- 板块龙头放量突破  
- 二线标的同步补涨  
- STR 连续两天出现相同板块  
- 10:30 / 13:45 分时出现加速结构  

结论：
> STR + 分时 + 板块量能  
> 三者一致 → 轮动成立。

---

# ✔ 5. 轮动执行法（Execution）

## **执行法①：调仓，而不是清仓**
举例：

- NAURA 涨多 → 滞涨  
- 当天 STR：侨源 / 川仪 / 星图  

→ 从 NAURA 拿出 **20% 仓位**  
→ 放入二线分支  

**不是卖光龙头，是调整仓位结构。**

---

## **执行法②：小仓试 → 量能确认 → 加仓**
尤其适用：

- 侨源  
- 川仪  
- 中科星图  

这是你历史上最稳定的盈利模式。

---

## **执行法③：主线衰退 → 回到 Core / Defensive**
- 板块缩量  
- ETF 跌破 MA20  
- 大盘黄灯  

→ 回收攻击仓  
→ 只留龙头（Core）或防御仓  

---

# ✔ 6. 轮动的本质

- 避免被单票横盘消耗  
- 资金永远跟随“最热方向”  
- 账户净值以最快斜率增长  
- AI + 你的分时判断 → 同步强化  

---

# ✔ 一句话总结

**TRF 的轮动不是换股，而是 “在科技主线 + 可变风口” 中做高低切换，  
让仓位永远处于资金密集区。**
