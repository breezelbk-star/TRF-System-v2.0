# 1.2 Rotation — 板块轮动系统（最终版）

轮动（Rotation）是 TRF 的第二核心：  
**不是换股，而是把仓位移动到“最强资金方向”。**

主线永远不是人工主观决定，而是由 **政策 + 资金 + 板块趋势** 三者共同决定。

---

# ✔ 1. 主线判定（Market Leadership）

TRF 系统始终围绕科技成长方向构建，主线必须来自：

## **A. 科技成长固定主线（长期）**
这些方向永远属于“可参与的主线池”：
- 半导体（设备 / 材料 / 设计 / 封测）
- AI 服务器 / GPU / HBM / 算力基础设施
- 信创 / 安全计算 / 工控系统
- 军工电子 / 卫星互联网
- 智能驾驶 / 机器人

> 这些方向是「永远有长期逻辑」的科技成长主线，  
> 不会因为短期调整而剔除，GitHub 内核可长期保留。

---

## **B. 可变风口主线（短期）**
由 **资金强度 + ETF 放量 + 策略选股出现频率** 决定，  
可能短期加入主线池：

- 某科技子分支突然放量（如光模块、动力 IC、EDA）
- 次主线：工业互联网、工控仪表、边缘计算
- 政策突然催化：国企改革 / AI 安全 / 数据要素

> 原则：**只要方向属于“科技范畴”，就可以作为短期主线参加轮动。**  
> 非科技方向（煤炭/消费/医药/黄金）不进入 TRF 主线池。

---

# ✔ 2. 账户内部角色体系（仓位结构）

为了避免“单票深套、错过轮动”等问题，你的账户始终坚持四层结构：

## **2.1 核心龙头仓（Core Leader）**
- 主线中最强、最纯正的龙头  
- 如：NAURA、寒武纪、中科曙光、北方华创  
- 仓位可达：**20%–40%**

用途：吃主升浪、稳定趋势、降低试错失败率。

---

## **2.2 进攻轮动仓（Aggressive Rotation）**
- 捕捉“下一棒”的位置  
- 如：侨源（材料）、川仪（工控）、中科星图（卫星测绘）  
- 仓位：**10%–25%**

用途：提升收益斜率，用于捕捉 3–10 日的快速主升。

---

## **2.3 防御仓（Defensive）**
- 在三色风险灯处于黄灯/红灯时启用  
- 包括：高股息、电力、运营商（仅在科技弱周期时）  
- 仓位：**0–30%**

用途：降低波动、保持稳定。

---

## **2.4 试错仓（Test）**
- GPT 选股池中出现的新热点  
- 小仓验证逻辑（3–5%）  
- 成功 → 晋升到进攻仓  
- 失败 → 快速清仓

---

# ✔ 3. TRF 轮动原则（执行逻辑）

## **原则 1：轮动只在“科技主线内部”切换**
举例：
- 半导体 → 子分支设备 → 子分支材料 → 子分支设计  
- AI 服务器 → GPU → 存储 → 电源管理  
- 信创 → 服务器 → 软件 → 安全计算

❌ 不会从半导体切到煤炭  
❌ 不会从 AI 切到医药  
这些方向不属于 TRF 系统。

---

## **原则 2：强者恒强，低位补涨**
- 主升浪中：抓“最强”  
- 次日龙二/龙三补涨：抓“低位启动”  
- 高位滞涨：主动切走，不等套牢

---

## **原则 3：龙头震荡 → 下一个分支突破 → 立即切**
例子：
- NAURA 横盘时  
- 侨源 / 川仪 / 中科星图突破  
→ 将部分仓位从龙头挪至进攻仓

这是你捕捉“侨源第二波”的关键逻辑。

---

# ✔ 4. 轮动触发信号（Rotation Trigger）

满足任意两条，即视为轮动信号出现：

- 板块 ETF 放量突破 MA20  
- 板块指数放量 ≥ 1.7 倍  
- 板块龙头加速、二线补涨跟随  
- GPT 盘后选股连续 2–3 日出现同类板块  
- 盘中 10:30 / 13:45 出现分支突破

当你看到：
> **策略选股中连续两天出现“相同板块的不同股票” → 说明轮动方向已经成立。**

---

# ✔ 5. 轮动执行法（最重要部分）

## **执行法 ①：不是卖掉强者，而是重新分配仓位**
例如：
- NAURA 涨多 → 滞涨  
- 当天策略选股：侨源 / 川仪 / 中科  
→ 从 NAURA 拿出 20% 仓 → 放入侨源等新分支  
❌ 不卖光龙头  
✔ 是“调仓”，不是“清仓”

---

## **执行法 ②：突破加速 → 小仓试 → 量能确认 → 加仓**
这正是你擅长的侨源/川仪逻辑。

---

## **执行法 ③：主线衰退 → 立即回防**
- 板块缩量 → 回到龙头  
- 大盘弱 → 转为防御仓  
- 红灯 → 仓位 ≤ 40%

---

# ✔ 6. 轮动的本质

- 避免被单票震荡  
- 资金永远跟在“最热、最强逻辑”后面  
- 让账户净值以“斜率最大化”的方式上涨  
- 通过 AI 每日盘前 / 盘中 / 盘后的动态判断，让你永远踩在节奏上

---

# ✔ 一句话总结
**TRF 的轮动不是乱换股，而是在“科技主线 + 可变风口”中做高低切换，  
把仓位永远放在“资金最密集的方向”。**
