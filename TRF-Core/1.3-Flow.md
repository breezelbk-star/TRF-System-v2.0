## 1.3 Flow（资金）

Flow 维度核心观察：**量价关系 + 换手 + 资金净流向**（以东方财富等软件数据为准）

---

## 🟦 一、量价行为（基础逻辑）

### ✔ 放量上涨（健康与危险的分界线）
- 若价格创新高 + 成交明显放大  
  → 主力持续加仓，属于**健康放量**；
- 若放量但收长上影 / 高位巨量横盘  
  → 警惕派发，需考虑部分止盈。

### ✔ 缩量回调
- 上涨后的 **缩量阴线 / 小阴小阳**、不破关键支撑（MA5 / MA10 / MA20）  
  → 属于健康洗盘；
- 若缩量跌破 MA20 甚至 MA60  
  → 视为趋势走弱，进入风险区。

### ✔ 换手率（判断趋势是否真实）
- 启动阶段换手 >5% → 有利于主升；  
- 高位巨量换手（>15%–20%）但未突破  
  → 多为派发，提高警惕。

---

## 🟦 二、Flow 决策解释器（最关键的操作版）

Flow 不只是观察强弱，更是实际操作依据。

### 🟢 Flow 强（放量长阳 / 放量突破 / 换手温和放大）
代表：**主力在加仓，趋势具备延续性**
- 可保持或适度加仓（在突破关键价位时）  
- 若已持仓 → 优先拿住  
- 回踩 MA5 属强势结构，不作为卖点  

### 🟡 Flow 中性（缩量震荡 / 小阴小阳 / 缩量整理）
代表：**观望状态**
- 不追涨  
- 看 MA10 / MA20 是否承接  
- 若接近压力位 → 大概率冲高回落  
- 持仓以等待为主，降低操作频次

### 🔴 Flow 弱（放量长阴 / 高位巨量不涨 / 缩量跌破均线）
代表：**主力出货或情绪快速退潮**
- 必须执行部分减仓或止盈  
- 放量跌破 MA20 → 结构转弱  
- 跌破 MA60 → 趋势破坏，进入防御模式  
- 不做“越跌越补”，等待新结构出现  

---

## 🟦 三、Flow 三条铁律（侨源/川仪模型总结）

1. **放量突破必须跟随，不跟则跌（侨源模型）**  
2. **堆量稳步推升最健康（川仪模型）**  
3. **高位巨量不涨 = 主力派发警告（必减仓）**

---

## 🟦 四、Flow 与 TRF 三维联动（更重要）

Flow 并不独立决策，必须同时满足：

- **Trend（趋势）**：均线结构  
- **Rotation（板块轮动）**：主线 / 分歧 / 接力  
- **Flow（资金）**：实际有无资金真正在买  

只有 **Trend + Rotation + Flow = 三线共振**  
才是最佳进攻窗口。



> **本质原则：Flow 是市场“正在发生什么”的真实信号，是所有买卖点的最终确认器。**
