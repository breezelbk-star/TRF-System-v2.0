# 1.5 Execution — 执行系统（最终版）

> Execution = TRF 的“实盘指挥系统”  
> 用来统一：Trend / Rotation / Flow / Risk / My-Style  
> 并通过每日固定动作，让交易实现自动化、流程化。

本文件是 TRF v2.0 的核心文件之一。

---

# ✔ 1. Execution 的作用（核心定义）

1. 决定每天“怎么做”  
2. 决定在什么状态可以/不能进攻  
3. 决定仓位如何调整  
4. 决定你什么时候该稳、什么时候该冲  
5. 决定 AI 每日应该给你怎样的策略输出

Execution = 你实盘的“驾驶舱系统”。

---

# ✔ 2. 执行系统的五大原则（必须写入内核）

### **原则 ①：风险灯优先（Risk → Trend → Rotation）**
```
红灯：停止进攻  
黄灯：控制节奏  
绿灯：放开做  
```

### **原则 ②：先判断大盘，后判断板块，再判断个股**

### **原则 ③：早上不冲动，下午才确认**
- 9:30–10:00 是你最容易犯错的时段  
- 13:45 是当天最重要的决策窗口

### **原则 ④：突破必须确认，补涨必须强于指数**

### **原则 ⑤：每天只有两件事：**
- 保护资金  
- 抓住主升浪

---

# ✔ 3. 每日流程（固定执行节奏）

Execution 所有行为分为五段：

## ——① 盘前（AI 自动生成策略 · 你无需截图）
AI 会根据你前一天收盘截图 + 选股池 + 大盘：

生成：
- 今日风险灯（绿/黄/红）  
- 今日持仓关键位（支撑/压力/攻击/防守位）  
- 今日主线方向  
- 今日操作节奏（加仓 / 低吸 / 观望）  
- 今日不允许做的事  
- 需要特别关注的分支（如：设备/材料/卫星等）

你无需提供截图，AI 会自动给出策略。

如果你在 9:30–9:45 给截图（如：集合竞价异常），  
AI 会即时修正策略。

---

## ——② 盘中第一次检查（10:00 固定检测）
检查方向是否成立：

- 指数是否出现“冲高回落”  
- 主线板块是否放量 or 转弱  
- 持仓是否强于板块  
- 是否出现假突破  

动作：
- 若强 → 继续观察  
- 若弱 → 中午前减少进攻行为  
- 若出现假突破 → 标记风险标签（Risk-Tag）

---

## ——③ 中午复盘（11:30）
动作：

- 判断上午趋势是否有效  
- 判断量能是否健康（缩量回调 or 放量回落）  
- 判断持仓是否守住关键位  
- 判断是否有新的“轮动方向”出现  
- 判断是否需要下午加仓 / 做 T / 等待  

午间是“第一次真正的修正点”。

---

## ——④ 下午确认（13:45 关键窗口）
这是 TRF 极为重要的框架：

如果你看错上午，  
下午 13:45 可以完全纠正。

判断：

- 是否出现下午右侧信号（放量拉升）  
- 是否出现主线加速  
- 是否出现板块分支补涨  
- 是否出现尾盘派发  
- 是否需要减仓、兑现、加仓  

动作：

- 强 → 加仓 / 做 T  
- 中 → 不动  
- 弱 → 减仓、锁定利润、保护仓位

---

## ——⑤ 收盘（15:00）
你给我三张截图：

- 持仓  
- 大盘 & 板块  
- GPT 选股池  

AI 输出：

- 次日关键位  
- 次日策略计划  
- 次日风险灯推演  
- 当前持仓评分（Core / Attack / Test）  
- 轮动方向是否继续  
- 是否需要调整仓位结构  
- 哪只股票是“下一棒候选人”

---

# ✔ 4. 盘中动作规则（行为标准）

### **4.1 允许加仓的情况（必须满足 2 条）**
- 绿灯  
- 分时放量突破  
- 日线结构强（5>10>20）  
- 主线同步走强  

---

### **4.2 必须减仓的情况（任意 1 条）**
- 红灯  
- 放量长阴  
- 跌破关键位（MA20 / 前低）  
- 假突破（冲高回落 + 放量）  

---

### **4.3 不允许开仓的时间**
- 09:30–09:45  
- 14:45 以后  

这是你失败案例（中国长城）复盘的重点。

---

# ✔ 5. 与 My-Style-Model 的联动

Execution 每一步都会自动检查：

- 当前标的是不是你的成功模式（Core / AR / AC）  
- 是否触发你的失败模式（假突破、无量、跌破关键位）  

任何“不符合你成功模式”的标的，  
AI 会自动拒绝推荐。

---

# ✔ 6. 与 Fail-Cases 的联动

如果出现你曾经的失败场景：

- 冲高回落  
- 无量假突破  
- 下跌不止  
- 越跌越补的冲动  

AI 会自动触发：

```
⚠️ FAIL-PATTERN DETECTED（已触发失败模式）
```

并给你替代动作。

---

# ✔ 7. 与 Risk 模块的联动（最重要）

Execution 的所有动作都要看“风险灯”：

```
绿灯：可以执行所有进攻动作  
黄灯：只能做低吸，不做突破  
红灯：只允许减仓，禁止加仓  
```

Execution 的优先级顺序为：

```
Risk → Trend → Rotation → Flow → Execution
```

---

# ✔ 8. 一句话总结

> **Execution 是“怎么做”的系统，是 TRF 的发动机。  
>  Trend 是方向，Rotation 是切换，Flow 是油门，Risk 是刹车。  
>  Execution 让整部车按你的方式跑起来。**
