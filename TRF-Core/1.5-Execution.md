# 1.5 Execution — 执行节奏系统（TRF v2.0 最终版）
> 本模块定义你每天从开盘前到收盘后的 **完整标准化操作流程**。  
> 所有实盘建议（盘前 / 盘中 / 午盘 / 尾盘）都要严格按照本文件执行。  

TRF Execution =  
**三色风险灯（环境） + 身份标签（股票定位） + 五段节奏（标准动作）**

---

# 🧩 0. 执行系统三大基础

## ✔ 0.1 三色风险灯（决定当天能否进攻）
- 🟩 **绿灯**：允许进攻、允许加仓、允许轮动  
- 🟨 **黄灯**：只可低吸，不可加仓，不可追高  
- 🟥 **红灯**：禁止开仓、禁止加仓、必须降仓

风险灯的判断规则见 `1.4-Risk.md`。

---

## ✔ 0.2 股票“身份标签机制”
每一只股票都必须先被定义角色：

| 标签 | 含义 | 仓位上限 | 行为 |
|------|------|-----------|--------|
| **Core（核心龙头）** | 主线最强方向的龙头 | 20–40% | 长持 + 波段 |
| **Attack（进攻轮动）** | 主线下一棒、分支补涨 | 10–25% | 短中线主升段 |
| **Defensive（防御）** | 稳定、防御、低波动 | 10–30% | 用于红/黄灯替代 |
| **Test（试错）** | 今日热点、新标的验证 | 3–5% | 快速试错 |

AI 在盘前必须告诉你每只股票属于哪一类。

---

## ✔ 0.3 今日五段执行节奏（核心流程）
每天必须严格执行以下 **五段式节奏**：

1. **盘前（08:30–09:00）判定当天环境（绿/黄/红）**  
2. **10:00 盘中第一次检查 → 判断上午是否真实**  
3. **11:30 午盘 → 判断上午强弱，调整下午计划**  
4. **13:45 下午主决策点 → 判定是否尾盘要行动**  
5. **15:00 收盘 → 为明天制定结构化计划**

---

# 🟩 1. 盘前（08:30–09:00）  
> 目的：决定今天是“进攻 / 观察 / 防御”

AI 必须根据你提供的截图（指数 + 持仓）输出：

### ✔ 环境判定  
- 今天是 **绿灯 / 黄灯 / 红灯**

### ✔ 检查项目  
1. 上证/创业板是否站在 MA20 / MA60 上方  
2. 半导体 / AI / 信创 ETF 是否放量  
3. 你的核心持仓是否在关键位之上  
4. 今日策略选股与昨日主线是否一致  

### ✔ 输出动作（AI 必须给你）
- 今日仓位建议（xx–xx%）  
- 今日攻击位 / 防守位  
- 哪些股票今天可操作  
- 如果绿灯 → 今日可加仓  
- 如果黄灯 → 今天禁止追高  
- 如果红灯 → 今天禁止新开仓  

---

# 🟨 2. 盘中第一次检查（10:00）
> 目的：确认早盘上涨/突破是否真实

AI 必须判断：

### ✔ 指数  
是否出现放量杀跌 / 假反弹

### ✔ 主线板块  
是否放量同步走强  
是否出现“冲高回落”

### ✔ 你的个股  
5 分钟结构是否健康  
是否出现“冲高放量长上影”  
是否出现“放量破位”

### ✔ 行动  
- 强 → 不动，等待午盘  
- 弱但未破位 → 中午再验证  
- 放量破位 → 提前触发风控（考虑减仓）

---

# 🟧 3. 午盘（11:30）
> 目的：判断上午的方向是否有效，决定下午做不做

AI 必须分析：

### ✔ 上午走势
- 真强？假强？  
- 是放量上涨还是缩量震荡？

### ✔ 盘中结论  
- 上午强 → 下午计划：允许 T / 允许试探加  
- 中性 → 保持不动  
- 上午弱 → 下午需“偏防御策略”

### ✔ 午间关键提醒  
AI 必须告诉你：
- 下午哪只票最强？  
- 哪只票最危险？  
- 是否出现分支轮动？  
- 下午要不要继续看 13:45 ？

---

# 🟥 4. 下午 13:45（最关键）
> 目的：决定是否尾盘加仓 / 减仓 / 观望

AI 必须判断以下内容：

### ✔ 判断三项  
1. 大盘是否走出“右侧信号”  
2. 主线是否出现二次攻击  
3. 个股是否走出趋势延续 or 明显走弱  

### ✔ 尾盘动作  
- 强势结构 → 可少量做 T 或轻仓加  
- 震荡结构 → 不动  
- 走弱结构 → 尾盘减仓 10–30%  

此处是避免你被尾盘杀跌的关键机制。

---

# 🟦 5. 收盘（15:00）
> 目的：为明天做完整准备

AI 必须输出：

### ✔ 每只持仓股票：
- 身份标签（Core / Attack / Defensive / Test）  
- 明日关键支撑（S1/S2）  
- 明日攻击位（A1/A2）  
- 明日防守位（D）  

### ✔ 明日环境预测：
- 明天可能是绿灯 / 黄灯 / 红灯哪个区间？  
- 明天主线方向排序（1 → 2 → 3）

### ✔ 换仓建议  
- 是否要把弱票换到今日策略池的强票？  
- 是否要锁定部分利润？  

---

# 🔐 6. 行为纪律（Execution Rules）

为了避免你进入“中国长城模式”，AI 必须强制执行以下纪律：

### ❌ 不允许的行为  
- 09:45 前追高  
- 14:45 后开新仓  
- 越跌越补  
- 黄灯/红灯时做进攻动作  
- 无突破、无量能的情况下建仓  
- 在横盘 5–7 天的票上浪费时间  

### ✔ 允许的行为  
- 绿灯 → 全流程进攻  
- 黄灯 → 只低吸，不追高  
- 红灯 → 严格防御，只保留底仓  

---

# 🎯 Execution 的核心意义
通过固定流程 + 风险灯 + 身份标签，  
AI 将保证你每天的交易是：

- 有节奏  
- 有纪律  
- 不情绪化  
- 不随意满仓  
- 不会在错误时段进攻  
- 永远踩在主线上  

---

# ✔ 一句话总结  
**Execution = 你每日的“操作地图”。  
任何实盘建议都必须严格按 Execution 流程生成。**
