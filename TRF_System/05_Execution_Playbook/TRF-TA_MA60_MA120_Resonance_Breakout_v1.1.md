⬛        TRF-System v1.1 ｜ MA60 / MA120 共振突破执行标准          ⬛
⬛                                                                  ⬛
⬛【适用前提】                                                      ⬛
⬛  • 日线级别趋势潜力股                                            ⬛
⬛  • 前期经历 ≥10 个交易日横盘 / 缓慢下行                          ⬛
⬛  • 非连续拉升后的高位区                                          ⬛
⬛                                                                  ⬛
⬛【横盘区间上沿定义】                                              ⬛
⬛  • 最近 10–30 个交易日内                                          ⬛
⬛  • 至少 2 次以上高点受阻回落                                      ⬛
⬛  • 低点不再持续创新低                                            ⬛
⬛  • K 线实体主要集中在相对固定价格区间                            ⬛
⬛                                                                  ⬛
⬛  → 最近多次未能有效站稳的最高价 = 横盘区间上沿                   ⬛
⬛                                                                  ⬛
⬛【MA60 / MA120 共振判定（核心）】                                 ⬛
⬛  • 同时存在 MA60 与 MA120                                        ⬛
⬛  • MA60 与 MA120 处于相互靠近 / 交汇 / 重叠区                     ⬛
⬛  • |MA60 − MA120| ÷ MA120 ≤ 2–3%                                  ⬛
⬛  • 共振持续时间 ≥8–15 个交易日                                   ⬛
⬛                                                                  ⬛
⬛  说明：                                                          ⬛
⬛  • 共振阶段允许 MA60 向下、MA120 向上或走平                      ⬛
⬛  • 不要求金叉                                                    ⬛
⬛  • 共振本质为中期与中长期资金成本密集区                          ⬛
⬛  • 对股价形成“压制墙”                                           ⬛
⬛                                                                  ⬛
⬛【有效突破定义（必须一次性满足）】                                ⬛
⬛  • 单日放量长阳                                                  ⬛
⬛  • 成交量 ≥ 近 5 日均量的 1.5–2 倍                                ⬛
⬛  • 实体同时突破：                                                ⬛
⬛      - 横盘区间上沿                                              ⬛
⬛      - MA60 / MA120 共振压制区                                   ⬛
⬛  • 收盘价站稳突破位                                              ⬛
⬛                                                                  ⬛
⬛【买入逻辑核心】                                                  ⬛
⬛  • 该突破不是“解套行情”                                         ⬛
⬛  • 而是新资金一次性越过中期 + 中长期成本墙                      ⬛
⬛  • 代表趋势资金开始主导                                          ⬛
⬛                                                                  ⬛
⬛【执行策略】                                                      ⬛
⬛  情景 A｜突破当日                                                 ⬛
⬛    • 仅允许小仓位试探                                             ⬛
⬛                                                                  ⬛
⬛  情景 B｜突破后回踩                                               ⬛
⬛    • 回踩不破横盘上沿或 MA60                                      ⬛
⬛    • MA20 / MA30 拐头向上                                        ⬛
⬛    → 允许正常介入                                                ⬛
⬛                                                                  ⬛
⬛【风险失效条件】                                                  ⬛
⬛  • 突破后 3 日内跌回横盘区                                        ⬛
⬛  • 或收盘价重新跌回 MA60 / MA120 共振区                          ⬛
⬛                                                                  ⬛
⬛  → 判定为假突破，立即退出                                        ⬛
