# TRF_A_Entry_Template ｜ MA60 / MA120 共振突破模型 映射说明（v1.1）

## 一、模型在 TRF-A 体系中的定位

MA60 / MA120 共振突破模型：
- 属于 **TRF-A（右侧趋势启动）子模型**
- 定位为：**中期压制解除 → 新趋势启动**
- 不参与左侧抄底、不参与情绪博弈

该模型的核心作用：
→ 从「中期与中长期资金成本密集区」中，筛选 **可能进入趋势主升段的个股**

---

## 二、允许使用 TRF_A_Entry_Template 的股票类型（✅）

以下股票 **允许** 使用 TRF_A_Entry_Template 执行：

### 1️⃣ 结构条件（必须全部满足）
- 日线级别存在 MA60 与 MA120
- MA60 与 MA120 曾出现：
  - 靠近 / 交汇 / 重叠
  - |MA60 − MA120| ÷ MA120 ≤ 2–3%
- 共振持续 ≥ 8–15 个交易日
- 共振期间成交量整体萎缩或平稳

### 2️⃣ 位置条件
- 股价处于：
  - 横盘区间上沿附近
  - 或 MA60 / MA120 共振压制区附近
- 非连续拉升后的高位区
- 非单边急涨后的追高位置

### 3️⃣ 突破行为
- 出现 **单日放量长阳**
- 成交量 ≥ 近 5 日均量的 1.5–2 倍
- 实体一次性突破：
  - 横盘区间上沿
  - MA60 / MA120 共振压制区
- 收盘价站稳突破位

👉 满足以上条件的个股  
→ **允许启用 TRF_A_Entry_Template（情景 A / B 执行）**

---

## 三、明确禁止使用 TRF_A_Entry_Template 的股票类型（❌）

以下情况 **严禁** 使用 TRF_A_Entry_Template：

### ❌ 1️⃣ 非共振结构票
- MA60 与 MA120 长期大幅分离（＞5–8%）
- MA120 明显单边向下
- 不存在成本密集区，仅是反弹

→ 判定为 **反弹结构票**，不属于 TRF-A

---

### ❌ 2️⃣ 情绪拉升 / 连板型
- 连续涨停或接近连板
- 日内巨幅拉升后放量震荡
- 明显游资主导盘口特征

→ 属于 **TRF-S（情绪）或禁区**
→ 禁止用 TRF_A_Entry_Template

---

### ❌ 3️⃣ 高位加速票
- 已远离 MA60 / MA120（＞10%）
- MA60 已陡峭上行，价格严重乖离
- 属于趋势后段或加速尾声

→ TRF-A 只吃“启动段”，不吃“加速尾段”

---

## 四、在 TRF_A_Entry_Template 中的具体执行映射

### 情景 A｜突破当日
- 条件：
  - 满足共振突破定义
- 操作：
  - 仅允许 **小仓位试探**
  - 禁止一次性满仓
- 目的：
  - 确认突破有效性，而非博弈涨幅

---

### 情景 B｜突破后回踩（核心使用场景）
- 条件：
  - 回踩不破横盘区上沿 或 MA60
  - MA20 / MA30 拐头向上
  - 成交量明显缩量
- 操作：
  - 允许正常介入
  - 可作为主仓建立点

---

## 五、失效即退出（TRF-A 硬纪律）

任一情况触发 → **无条件执行 Exit**

- 突破后 3 日内：
  - 收盘价跌回横盘区
  - 或重新跌入 MA60 / MA120 共振区
- 放量长阴吞没突破阳线
- 回踩中 MA20 / MA30 明确拐头向下

---

## 六、一句话总结（写给未来的自己）

MA60 / MA120 共振突破模型：
不是为了抓最低点，
而是为了在 **“中期压制被一次性跨越”时，
第一时间站到趋势资金一侧。**
