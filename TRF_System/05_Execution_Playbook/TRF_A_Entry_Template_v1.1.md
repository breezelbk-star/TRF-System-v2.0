【适用前提｜不满足直接放弃】
1. 日线趋势已确立：
   - MA20 / MA30 明确向上
   - 已出现至少一次“放量突破 / 加速行为”
2. 个股不在系统性高风险期
   （非指数暴跌、非情绪退潮首日）

────────────────────────────
一、是否进入「允许介入阶段」判断
（三条必须同时满足）

□ ① 趋势未破
   - 日线未有效跌破 MA20
   - MA20 / MA30 斜率仍为正

□ ② 回踩性质正确
   - 回踩幅度 ≤ 6%
   - 无连续放量大阴线
   - 下影线 ≥ 实体（承接存在）

□ ③ 量能逻辑成立
   - 回调缩量
   - 企稳/反弹时量能回升

→ 三条全满足，才允许进入下一步

────────────────────────────
二、TRF_A 允许的三种回踩结构

【模式 A｜最优】
高位横盘消化型（胜率最高）

结构特征：
- 突破后横盘 1–3 天
- 振幅逐步收敛
- MA5 / MA10 向上贴近
- 成交量明显缩小

介入信号：
- 横盘区间内首次放量阳线
- 或盘中回踩不破横盘下沿

仓位规则：
- 首次介入 30%–40%

────────────────────────────
【模式 B｜次优】
MA10 / MA20 技术回踩型

结构特征：
- 回踩 MA10 或 MA20
- 回踩过程中量能持续缩
- 日线出现：
  十字星 / 小实体 + 下影线

介入信号：
- “止跌K线”确认后
- 配合分时企稳（见第四部分）

仓位规则：
- 20%–30%，可分两次

────────────────────────────
【模式 C｜禁止】
情绪性快速下杀（绝对不做）

典型特征：
- 放量大阴线
- 快速跌破 MA10
- 连续两根以上实体阴线

TRF 定义：
- 主升结构开始松动
- 禁止抄底、禁止试错

────────────────────────────
三、介入后的硬性风控线（必须同步设定）

【风控线】
- 日线有效跌破 MA20
- 或回踩低点被放量击穿

→ 无条件减仓 / 清仓
→ 不允许“再等等看”

【持有确认线】
- 再次放量突破前高
- 或 MA5 / MA10 再度发散上行

→ 才允许加仓
→ 否则只持不动

────────────────────────────
四、v1.1 新增｜分时确认细则（关键升级）

以下条件至少满足 2 条，才允许下单：

□ 1. 分时不再创新低
   - 连续 20–30 分钟低点抬高

□ 2. 5 分钟结构修复
   - MA5 上穿 MA10
   - 回踩不破前低

□ 3. 分时均价线（黄线）
   - 价格重新站上
   - 且黄线走平或拐头向上

→ 未满足分时确认：
  日线再好，也不提前介入

- 未出现二次确认，禁止满仓
- 单票最大风险暴露 ≤ 总资金 8%
