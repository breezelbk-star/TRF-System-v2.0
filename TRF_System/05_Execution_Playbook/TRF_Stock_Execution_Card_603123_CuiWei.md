# TRF 个股执行卡｜翠微股份（603123）
模型：TRF-TA｜MA60 / MA120 共振突破 v1.1

────────────────────────────────────
一、个股定位（定性）
────────────────────────────────────
• 日线级别放量长阳
• 一次性突破横盘区上沿 + MA60 + MA120
• 收盘价有效站稳共振区之上
• 非解套结构，判定为趋势启动型

结论：
趋势确认完成，但只做结构性介入，不追高

────────────────────────────────────
二、关键结构区（必须盯）
────────────────────────────────────
MA 参考（突破当日）：
• MA60 ≈ 12.20
• MA120 ≈ 13.08

结构区间划分：
• MA60 / MA120 共振压制区（已突破）：12.20 – 13.10
• 原横盘区上沿：≈ 13.00
• 突破收盘价：14.12

────────────────────────────────────
三、ENTRY（首次建仓）
────────────────────────────────────
情景 A｜回踩确认（优先级最高）

允许介入区：
• 13.00 – 13.30（横盘上沿 + 共振区）
• 或 13.30 – 13.60（突破实体回踩 1/2）

必须同时满足：
• 日线收盘不跌回 13.00 下方
• 回踩期间成交量明显低于突破当日
• 15 / 30 分钟级别出现止跌结构
  （下影线 / 小实体 / 缩量横住）

执行方式：
• 首仓 30%–40%
• 只在回踩止跌确认后介入
• 严禁盘中情绪追高

────────────────────────────────────
情景 B｜高位横盘再走强（次优）
────────────────────────────────────
形态要求：
• 13.80 – 14.20 区间横盘 ≥2 个交易日
• 成交量持续收敛
• MA20 / MA30 明确拐头向上
• 再次放量突破小平台高点

执行方式：
• 右侧跟随
• 仓位低于回踩情景
• 不加速、不追涨

────────────────────────────────────
四、ADD（加仓规则）
────────────────────────────────────
允许加仓的唯一条件：
• 回踩完成后再次放量突破前高
• 日线 MA20 / MA30 多头排列
• 回踩低点逐级抬高
• 市场无系统性风险

加仓方式：
• 加仓比例 20%–30%
• 只加一次，不滚动追高

────────────────────────────────────
五、EXIT（止损 / 失效）
────────────────────────────────────
无条件退出：
• 日线收盘跌回 13.00 下方
• 或重新跌回 MA60 / MA120 共振区
• 或突破后 3 个交易日内无法站稳结构位

主动降仓：
• 放量但价格明显滞涨
• 长上影线 + 成交量异常放大
• 明显情绪化拉升而非趋势推进

────────────────────────────────────
六、执行纪律
────────────────────────────────────
• 不因看好而追高
• 不因突破而幻想
• 买点只来自结构 + 量能 + 位置
• 趋势确认解决“能不能买”
• 回踩结构解决“值不值得买”
