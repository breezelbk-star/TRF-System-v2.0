【定位】
本纪律卡用于：
- L1 / L2 模型筛选之后
- 快速删除“看起来就不该碰的票”
- 让精力只花在“值得思考的少数标的”上

适用对象：
- TRF-T（趋势波段）
- TRF-A（侨源型 / 主升浪）

------------------------------------------------
【一】执行顺序（严格不可颠倒）

Step 1：模型初筛（不加市值）
Step 2：人工 30 秒一眼否定
Step 3：数量过多 → 再启用市值过滤
Step 4：归类进入观察池 / 删除

⚠️ 原则：
模型 ≠ 决策者
你 ≠ 参数执行器

------------------------------------------------
【二】30 秒“一眼否定”三问（核心）

对每一只 L1 股票，只问这三件事：

1️⃣ 这根 K 线结构像不像“主力在控盘”？
- 均线是否凌乱、反复穿插？
- 是否有大量长上影 / 长下影？
- 是否经常冲高回落、次日无承接？

👉 若“杂乱 / 情绪化” → 直接删除

2️⃣ 这是我愿意参与的行业吗？
- 科技 / 制造 / 半导体 / 高端装备 → 可继续
- 强周期（煤钢化工）/ 纯题材 → 降级或删除

👉 行业看不懂 = 不参与

3️⃣ 这是趋势，还是反抽？
- 是否仍被 MA60 / MA120 压制？
- 是否只是“跌多了反弹”？
- 是否缺乏前期主升结构？

👉 反抽 ≠ 趋势 → 删除

------------------------------------------------
【三】市值过滤的正确使用方式（非常重要）

市值不是“信号”，只是“风险标签”。

使用规则：

- L1 ≤20 只：
  → 完全不看市值，纯人工判断

- L1 = 20–40 只：
  → 人工先删，再看市值

- L1 >40 只：
  → 启用一次市值过滤作为兜底

------------------------------------------------
【四】市值分层参考（不写死）

🟢 优先观察区（最适合你）
- 150–600 亿
- 典型：华海清科、南大光电、早期阳光电源

🟡 可接受区（需更严格）
- 600–3000 亿
- 典型：北方华创（只做确认后的趋势）

🔴 高风险区（默认回避）
- <100 亿（除非侨源/长光那种控盘级别）
- >5000 亿（除非指数共振）

⚠️ 市值只用于“降噪”，不是“入场理由”

------------------------------------------------
【五】最终归类（每天必须完成）

对剩余股票，强制归类：

A 类：TRF-A（侨源型 / 主升浪）
- 控盘感强
- 不深回踩
- 时间换空间

T 类：TRF-T（趋势波段）
- MA30 之上
- 回撤健康
- 可吃 10%–25%

D 类：Delete（删除）
- 今天不对，未来也不盯

------------------------------------------------
【六】铁律（必须背下来）

- 看不懂 = 不做
- 像反抽 = 不做
- 参数再好，看着别扭 = 不做

宁可错过，
不做错误交易。

------------------------------------------------
【一句话总结】

模型负责“找方向”，
你负责“做取舍”。

这是 TRF 真正赚钱的核心。
