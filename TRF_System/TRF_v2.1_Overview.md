# TRF Investment System v2.1  
（Trend + Rotation + Flagship）

## 📌 系统总览
TRF v2.1 是一个面向趋势交易者的 A 股量化-半量化混合操作体系，核心目标：
1. 捕捉主升浪龙头（避免错过长光华芯、金道科技等翻倍股）
2. 避免持有弱趋势股票（降低时间成本）
3. 建立“侨源 → 下一龙头”的无缝接力体系
4. 通过评分系统使投资决策从主观走向结构化

---

## 📌 模块组成（6 大模块）

### 1. TRF-Trend 模块（趋势识别）
- 识别 30 日趋势斜率（核心因子）
- 识别趋势加速度（长光华芯暴涨关键）
- 趋势拐点监控（DIF 加速度 + 均线发散）

### 2. TRF-Pattern 模块（形态结构）
- 主升浪五段结构识别
- 低位筹码堆积结构
- 强势调整 vs 弱势横盘

### 3. TRF-Rotation 模块（板块轮动）
- 找到下一个热点（如半导体、光刻、信创、电力、电网安全）
- 自动识别行业资金流（优于传统指标）

### 4. TRF-Score 模块（综合评分）
评分公式（权重）：
- 趋势强度：30%
- 形态强度：25%
- 板块风口：25%
- 弹性因子：20%

评分结果：
- 90–100：龙头接力必选  
- 80–89：强势趋势可参与  
- 70–79：观察名单  
- ≤69：不参与  

### 5. TRF-Execution 模块（执行体系）
- 盘前检查  
- 盘中触发点（突破、假跌破、主升加速）  
- 盘后趋势评分更新  
- 仓位管理与止盈模块  

### 6. TRF-Flagship 模块（龙头体系）
- 判断龙一/龙二  
- 侨源 → 金道科技/长光华芯式接棒逻辑  
- 强势股回调买点 & 二次启动识别  

---

## 📌 系统输出（每日生成）
- 龙头池 Top10（自动排名）
- 龙头接力优先级（1～3 名）
- 次龙头观察池
- 危险形态提醒（顶部背离、缩量滞涨等）
- 三大操作点位：低吸、突破、T+0  

---

## 📌 系统目标
- 实盘减少 30% 以上无效交易  
- 锁定 2–4 只年度翻倍龙头  
- 提升强趋势持仓时间  
- 模型化决策，减少主观干扰
