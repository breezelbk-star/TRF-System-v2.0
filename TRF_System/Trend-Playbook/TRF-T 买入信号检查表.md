# TRF-T 买点触发清单（盘中是否能下手）

适用对象：
- 华海清科
- 北方华创
- 南大光电
- 所有 TRF-T（10%–25%）趋势模型个股

核心定位：
这是“能不能买”的清单  
不是预测，是执行许可

--------------------------------------------------

## 一、【盘前必须已满足的前提】

以下条件若不全部满足 → 当天禁止考虑买入

[ ] 1️⃣ 日线价格运行在 MA30 之上
[ ] 2️⃣ MA30 走平或向上（不允许下拐）
[ ] 3️⃣ 最近 1–3 个月有 ≥20% 主升行情
[ ] 4️⃣ 当前处于 10%–25% 回撤后的整理区
[ ] 5️⃣ 回撤阶段无连续放量长阴

--------------------------------------------------

## 二、【盘中买点触发（满足其一即可）】

### 🟢 A 类：趋势恢复型（最优先）

[ ] A1 放量阳线重新站上 MA10
[ ] A2 回踩 MA20 / MA30 后出现放量反包
[ ] A3 分时回踩不破 MA20，量能明显缩小

➡ 行动：
- 允许开仓 40%–60%

---

### 🟡 B 类：横盘突破型（次优）

[ ] B1 横盘 ≥5 个交易日
[ ] B2 成交量明显低于主升期
[ ] B3 放量突破横盘区上沿

➡ 行动：
- 允许开仓 30%–50%

--------------------------------------------------

## 三、【盘中否决条件（出现即取消买入）】

出现以下任意一条 → 当天不买

✖ 指数明显走弱（大盘破关键位）
✖ 个股放量冲高后快速回落
✖ 分时连续高点下移
✖ 情绪股、消息股、突发异动

--------------------------------------------------

## 四、【一句话买点纪律】

不抢第一根  
只买“趋势已经回来的那一刻”
