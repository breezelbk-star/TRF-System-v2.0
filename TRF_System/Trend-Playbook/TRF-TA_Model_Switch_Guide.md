# TRF-T（趋势） vs TRF-A（侨源型）双模型切换指引

目的：
避免“用错武器”
趋势期不等侨源
侨源期不做趋势

--------------------------------------------------

## 一、TRF-T（趋势模型）适用环境

满足以下大多数条件：

[ ] 指数震荡 / 缓慢上行
[ ] 主线明确但无情绪爆发
[ ] 大票（300–3000 亿）走趋势
[ ] 涨幅分布集中在 10%–25%

➡ 行动：
- 启用 TRF-T
- 主做 华海清科 / 北方华创 / 南大光电

--------------------------------------------------

## 二、TRF-A（侨源型）适用环境

满足以下特征：

[ ] 长期横盘后的突然爆量点火
[ ] 市值中小（50–200 亿）
[ ] 主升段速度极快
[ ] 分时极强，回踩极浅

➡ 行动：
- 启用 TRF-A
- 集中精力，只做 1–2 只

--------------------------------------------------

## 三、禁止混用原则（非常重要）

✖ 用 TRF-T 的耐心等侨源
✖ 用 TRF-A 的贪婪做趋势票
✖ 同一只股票反复切换模型

--------------------------------------------------

## 四、快速判断口诀

慢、稳、磨 → TRF-T  
快、猛、狠 → TRF-A  

--------------------------------------------------

## 五、你的个人最优解（定制）

- 80% 时间：TRF-T 稳定复制
- 20% 时间：等待 TRF-A 出现
- 一旦 TRF-A 出现 → 暂停其他操作

这是你目前最优、最安全的系统结构
