# TRF-T 加仓规则（什么时候才允许加）

核心原则：
加仓是奖励“正确走势”
不是为了解套，也不是因为便宜

--------------------------------------------------

## 一、【允许加仓的唯一前提】

以下条件必须全部满足：

[ ] 1️⃣ 初始仓位买入后浮盈 ≥ +5%
[ ] 2️⃣ 股价未跌破 MA20 / MA30
[ ] 3️⃣ 日线结构保持趋势完整
[ ] 4️⃣ 大盘未进入系统性下跌

--------------------------------------------------

## 二、【加仓触发条件（满足其一）】

### 🟢 情形一：突破加速

[ ] 放量突破前高
[ ] 收盘价接近当日最高
[ ] 成交量温和放大（非爆量）

➡ 操作：
- 加仓 20%–30%

---

### 🟢 情形二：趋势确认后二次回踩

[ ] 回踩 MA10 / MA20
[ ] 成交量明显缩小
[ ] 收盘价重新走强

➡ 操作：
- 加仓 10%–20%

--------------------------------------------------

## 三、【绝对禁止加仓的情况】

✖ 浮亏状态下
✖ 放量下跌
✖ 指数同步走弱
✖ 情绪主升浪末端
✖ “感觉还能涨”

--------------------------------------------------

## 四、【仓位上限纪律】

- TRF-T 单票最大仓位：70%
- 禁止满仓
- 禁止摊平

--------------------------------------------------

## 五、【一句话加仓纪律】

加仓只做一件事：
放大已经证明正确的判断
