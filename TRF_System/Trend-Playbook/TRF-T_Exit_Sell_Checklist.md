# TRF-T 趋势股卖点触发清单（盘中 & 尾盘通用）

适用对象：
- 华海清科
- 北方华创
- 南大光电
- 所有 TRF-T（10%–25%）趋势模型个股

核心原则：
卖点永远比买点重要  
卖点必须“机械化执行”，禁止临场幻想

--------------------------------------------------

## 一、【强制减仓信号】（出现即执行）

以下任意一条成立 → 立即执行减仓（不等确认）

[ ] 1️⃣ 日内放量冲高回落，收盘价 < 当日最高价 95%
[ ] 2️⃣ 15 分钟级别跌破 MA10 且无法快速收回
[ ] 3️⃣ 当日放量，但实体明显缩小（量价背离）
[ ] 4️⃣ 连续 2 根分时高点下移（冲高乏力）

➡ 执行动作：
- 减仓 1/3 或 1/2
- 目的：锁利润，不判断顶部

--------------------------------------------------

## 二、【趋势破坏卖点】（必须清仓）

以下任意一条成立 → 无条件清仓

[ ] 5️⃣ 日线收盘跌破 MA30
[ ] 6️⃣ 回撤跌破本轮趋势低点
[ ] 7️⃣ 放量长阴（实体 ≥4%）且次日无修复
[ ] 8️⃣ 大盘同步转弱（指数跌破关键均线）

➡ 执行动作：
- 清仓
- 不允许“等等看”

--------------------------------------------------

## 三、【目标位卖点（计划内）】

用于趋势健康但已进入收益区间

[ ] 9️⃣ 浮盈 ≥ +10% → 减仓 1/3
[ ] 🔟 浮盈 ≥ +15% → 再减 1/3
[ ] 1️⃣1️⃣ 浮盈 ≥ +20%～25% → 全部清仓

说明：
- 这是“收益兑现”，不是看空
- 趋势票可以少赚，但不能回吐

--------------------------------------------------

## 四、【禁止操作清单】

出现以下情况，禁止任何加仓或幻想

✖ 追高放量阳线
✖ 放量下跌接刀
✖ 逆指数硬扛
✖ “它是好公司所以不卖”

--------------------------------------------------

## 五、【一句话纪律】

卖点不需要完美  
执行比判断重要  
利润是减出来的，不是猜出来的
