TRF-T 可复制趋势股模型（10%–25%）
████████████████████████████████████████

【一】模型定位
- 目标收益：10%–25%
- 操作周期：3–15 个交易日
- 适用环境：非极端情绪期、非主升情绪浪
- 核心用途：趋势波段复制训练

【二】硬性准入条件（不满足即淘汰）
1. 日线价格必须运行在 MA30 之上
2. MA30 走平或明确向上（禁止下拐）
3. 近 1–3 个月内至少出现一波 ≥20% 主升行情
4. 主升后的回撤幅度为 10%–25%
5. 回撤期间不得出现连续放量长阴
   
日线在 MA30 之上
过滤的是：假反弹、弱趋势
	•	在 MA30 下方的反弹
👉 本质是下跌结构中的技术修复
	•	TRF-T 只做 趋势中的波段
	•	不做任何“反转猜底”
📌 这一条缺失 = 趋势不成立，直接淘汰

MA30 走平或向上（禁止下拐）
过滤的是：趋势衰退期
	•	MA30 下拐 = 中期趋势已经在走弱
	•	这种位置的反弹：
	•	容易 5%–8% 就结束
	•	容易走成“假突破 → 再杀”
📌 这一条缺失 = 胜率明显下降，直接淘汰

 近 1–3 个月至少一波 ≥20% 主升
这是整个模型的“灵魂条件”
它验证三件事：
	1.	有资金愿意在这只股上连续推升
	2.	市场已经完成过一次“趋势定价”
	3.	后续回撤才有“再启动”的意义
📌 没有 ≥20% 主升 → 这不是趋势股，只是震荡股

回撤幅度 10%–25%
这是可复制区间的核心
	•	<10%：
	•	高位强势震荡
	•	性价比低，容易追高
	•	25%：
	•	结构被破坏
	•	容易演变成趋势结束
📌 这一条不满足 = 风险/收益比失衡

回撤期间无连续放量长阴
这是资金态度的“底线检测”
	•	放量长阴 ≠ 洗盘
	•	在回撤期连续放量杀跌：
	•	说明主力在撤
	•	或筹码结构严重松动
📌 这一条缺失 = 极易买在“趋势尸体”上


【三】结构确认条件
- 回撤后横盘整理 ≥5 个交易日
- 整理阶段成交量显著低于主升期
- K 线实体收敛，无连续冲高回落
- 均线逐步收敛而非发散

【四】唯一允许的买点（满足其一）
A. 放量阳线有效站上 MA10
B. 回踩 MA20 / MA30 后出现放量反包
C. 横盘整理区上沿放量突破

【五】仓位管理规则
- 初始建仓：40%–60%
- 只允许顺趋势加仓
- 禁止满仓
- 禁止任何形式的摊平补仓

【六】止损纪律（无条件执行）
- 日线有效跌破 MA30
- 或跌破回撤低点
→ 当日或次日全部止损

【七】止盈纪律（机械执行）
- 浮盈 +10%：减仓 1/3
- 浮盈 +15%：再减 1/3
- 浮盈 +20%～25%：清仓离场

【八】模型禁区（出现即放弃）
- 情绪主升浪中段追高
- 首板 / 二板博弈
- 放量下跌接刀
- 基本面不清晰的小市值题材股

【九】核心原则
不预测、不抄底、不幻想
只吃趋势中段的确定性利润
