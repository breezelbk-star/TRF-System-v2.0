# TRF Case Library（案例库）

本目录用于存放 **TRF 系统的标准化案例（Case）**。

每一个 Case 都不是“复盘文章”，而是：
> **可被反复调用、对照、复刻的交易结构样本**

用于：
- 校准 TRF 扫描器（scanners）
- 对照盘中/盘后出现的候选股
- 训练自己对不同“主力推进手法”的识别能力
- 未来交由 AI / 系统自动比对（像不像某个 Case）

---

## 一、Case 的定位

TRF Case ≠ 个股分析  
TRF Case = **主力行为模型样本**

每个 Case 重点回答 4 个问题：

1. 这是哪一类主力结构？
2. 启动的“第一性信号”是什么？
3. 推进方式属于哪一型？
4. 哪些条件 **不可复刻**（风险边界）

## 三、如何使用 Case（操作手册）

### ✅ 盘后流程（推荐）

1. 当日 TRF 扫描器输出候选股
2. 先判断：
   - 像不像 Case_001（侨源）？
   - 像不像 Case_002（长光）？
3. 若相似度 ≥ 70%：
   - 允许进入观察 / 试仓
4. 若相似度 < 50%：
   - 不做，不纠结

---

### ✅ 盘中应对（非职业交易者）

- 不追分时
- 以 **Case 的“确认节点”** 为买点
- 宁可慢 1 天，也不做模糊结构
