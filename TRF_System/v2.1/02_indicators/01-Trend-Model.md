# 趋势模型 Trend Model（v2.1）

趋势评分由五个部分组成：

1. MA 结构（20%、30% 权重）
   - 多头排列 = 强
   - 平行 = 中
   - 空头 = 弱

2. 均线拐点（20%）
   - MA5、MA10、MA20 同时向上 = 强趋势初期

3. EMA Ribbon（20%）
   - EMA 8/13/21 向上发散 = 加速阶段

4. K 线结构（20%）
   - 若连续 3 根“红+缩量回踩” = 主升浪前兆
   - 若阳包阴 = 多头反攻

5. 成交量（20%）
   - 温和放量 + 缩量回踩 = 最优趋势

最终趋势得分 = 0–100 分。

80+ = 强趋势（如长光华芯）
60–80 = 形态良好（如金道科技）
40–60 = 等方向（如复旦微电）
<40 = 不参与
