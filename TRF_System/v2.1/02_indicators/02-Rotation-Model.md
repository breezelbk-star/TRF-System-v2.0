# 轮动模型 Rotation Model（v2.1）

轮动评分基于五个因素：

1. 主题热度（30%）
   - 是否为国家战略方向（半导体、光刻机、AI 服务器等）
   - 是否为当日龙虎榜主线

2. 龙头强度（20%）
   - 主线高度（连板数量）
   - 龙头换手率 >8%

3. 资金流（20%）
   - 北向资金加仓行业
   - ETF 放量情况

4. 板块内部的结构（20%）
   - 趋势股数量
   - 板块涨幅广度

5. 情绪周期位置（10%）
   - 加速期
   - 分歧期
   - 退潮期

70+ → 主攻板块  
50–70 → 关注  
<50  → 不碰
