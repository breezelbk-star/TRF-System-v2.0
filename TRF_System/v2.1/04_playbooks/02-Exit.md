# TRF v2.1 止盈止损体系（Exit Rules）

要点：买点决定输赢，卖点决定收益。

---

# 止损规则（必须执行）

## ① 趋势股止损
- 跌破 MA20 收盘 → 必须减仓或清仓  
- 跌破结构低点 → 立即止损  
- 单笔最大亏损不超过 5–8%

---

# 止盈规则（按类型）

# ① 强趋势股（侨源）
主升浪止盈位：
- 第一目标：前高附近  
- 第二目标：1.382 扩展位  
- 第三目标：1.618 扩展位（主升浪最强）

操作：
- 每到一个目标→ 部分锁仓 30%

---

# ② 爆发股（长光华芯/金道科技）
止盈逻辑：
- 大阳线后两天必须判断：强 vs 弱  
- 若连续两天缩量小阴线 → 持有  
- 若放量长上影或大阴 → 必须减仓

目标位参考：
- 涨幅 50% → 锁仓 1/3  
- 涨幅 80% → 锁仓 1/3  
- 涨幅 120% → 看板块情绪决定是否全部退出

---

# ③ 反转股（复旦微、华海清科）
止盈：
- MACD 顶背离  
- 放量大阴  
- 跌破 MA20 → 必须卖出

---

# ④ 龙头战法止盈
龙头二波结束标志：
- 成交量突然萎缩  
- 出现阴包阳  
- 龙头反包失败  
- 同板块龙二龙三开始补跌

龙头必须“涨停卖、跌停卖”  
涨停板附近减仓 1/3  
断板必须第一时间出
