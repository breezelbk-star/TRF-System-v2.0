# TRF v2.1 行情周期地图（Cycle Map）

市场永远在 4 个阶段循环，这决定：
- 你该不该进攻
- 哪些股票能买
- 龙头能不能涨大波段

---

# 🎯 阶段 1：启动期（Start Phase）
特征：
- 指数止跌  
- 行业出现“零星强势股”  
- 热点快速轮动  
- 龙虎榜活跃

操作：
- 轻仓试错  
- 布局底部 MACD 金叉股（华海清科）  
- 潜伏强行业第二梯队（中微、南大光电）

仓位：20–40%

---

# 🎯 阶段 2：主升期（Main Rising）
特征：
- 行业主线出现（半导体）  
- 龙头突破加速（长光华芯）  
- 趋势股数量快速增加  
- 板块 volume up（放量）

操作：
- 全力做主线龙头  
- 趋势股回调必买  
- 弹性股可尝试突破追击

仓位：70–100%（攻击期）

---

# 🎯 阶段 3：分歧期（Disagreement）
特征：
- 龙头冲高回落  
- 涨停高度下降  
- 板块内部二八结构严重  
- 资金开始流向第二题材

操作：
- 个股只低吸、不追涨  
- 做 T 减成本  
- 龙头二波回踩可参与

仓位：40–60%

---

# 🎯 阶段 4：退潮期（Cooling）
特征：
- 板块普跌  
- 龙头断板  
- 连板系统塌陷  
- ETF、北向流出

操作：
- 不开新仓  
- 清大部分仓位  
- 只持有强势趋势股（如北方华创）

仓位：0–20%

---

# 如何判断当前处于哪个阶段？

使用 Cycle Map 评分（0–100）：

- ≥80 → 主升期  
- 60–80 → 分歧期  
- 40–60 → 启动期  
- <40 → 退潮期  

---

# Cycle Map 给出的每日一句话策略

示例：
- “当前主线为半导体设备，处于主升期：进攻。”  
- “当前进入分歧期：仅做低吸，不追涨。”  
- “处于退潮期：轻仓等待下一轮启动。”

这是 TRF v2.1 最重要的战略文件之一。
