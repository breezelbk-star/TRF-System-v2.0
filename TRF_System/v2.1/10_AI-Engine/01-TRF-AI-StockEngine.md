# TRF v2.1 — AI 自动选股逻辑引擎（TRF-AI Stock Engine）

本文件描述 TRF 系统未来版本（v2.2 / v3.0）的核心自动化能力：  
**让系统每日自动捕捉潜在龙头股，并提前推送可能出现“起爆点”的股票名单。**

---

# 🧠 1. AI 自动选股的三层结构

TRF-AI = Trend × Rotation × Flow 三因子融合，并加入四类 AI 强化能力：

```
AI-Score = Trend_Score × Rotation_Score × Flow_Score × AI_Filters
```

---

# 🟦 2. 趋势评分（Trend_Score）

趋势评分由 5 大指标组成，每个 20 分，共 100 分：

| 模块 | 含义 | 为什么重要 |
|------|------|-------------|
| T1. 多周期均线共振 | MA5/10/20/60 全部上拐 | 长光华芯第一天即触发 |
| T2. 结构突破 | 突破最近 30–60 日压力位 | 判断是否进入主升浪 |
| T3. 缩量回踩 | 上升趋势中出现完美缩量 | 侨源即将进入此节奏 |
| T4. 中枢突破 | 离开震荡箱体 | 代表趋势强度 |
| T5. 周线趋势同步 | 周线趋势是否跟随 | 决定行情级别大小 |

趋势评分达到 80+ 分 → 进入 **趋势候选**。

---

# 🟧 3. 轮动评分（Rotation_Score）

TRF 的轮动模型包含 5 维：

| 维度 | 描述 |
|------|-------|
| R1. 板块强度相对全市场排名 |
| R2. 板块内部涨幅分布是否健康（不是一字板） |
| R3. 板块资金净流入趋势（3 日/5 日） |
| R4. 前排龙头是否出现连续涨停（情绪带动） |
| R5. 板块与指数是否形成“逆势强”结构 |

轮动评分 70+ → 表示“板块进入发酵期”。

---

# 🟥 4. 资金流评分（Flow_Score）

Flow 模块最能提前识别长光华芯、金道科技、侨源这类：

| 因子 | 判定方式 |
|------|-----------|
| F1. 换手节奏（分钟级） | 主升浪前通常出现加速换手 |
| F2. 量比曲线（小时级） | 爆发前量比上穿 2.0 |
| F3. 连续资金净流入（2–3 日） | 机构提前潜伏 |
| F4. 爆发前吸筹形态 | 典型的“凹口”结构 |
| F5. 大单结构 | 大单净流入与主动买比例 |

Flow_Score 达 80 → **即将爆发或正在爆发**

---

# 🟪 5. AI Filters（自动过滤）

AI 过滤器让全系统更干净，避免垃圾票：

| Filter | 规则 |
|--------|--------|
| F1. 排除低价垃圾股（< 10 元） |
| F2. 排除亏损股（净利润为负） |
| F3. 排除过度炒作（7 天涨幅 > 80%） |
| F4. 排除主力出货结构（放量下跌） |
| F5. 优先选择行业核心资产 |

最终得分公式：

```
FinalScore = (T × 0.35) + (R × 0.30) + (F × 0.30) + (AI_Filter × 0.05)
```

90+ 分 → 极品潜力龙头  
80–89 分 → 强势趋势股  
70–79 分 → 潜伏候选  
<70 → 忽略
