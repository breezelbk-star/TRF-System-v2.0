# TRF 模型检测器：稳定趋势模型（Huahai_Like Detector）
版本：TRF v2.1

用于识别类似“机构稳健趋势股”的结构（如华海清科）。

---

# 1. 模型特征（满足 ≥3 项）
## （1）周线趋势良好
- 周线 MA5/10/20 多头  
- 波动低、结构顺滑

## （2）回调浅
- 下跌不破 20 日线  
- 回踩缩量

## （3）主力资金持续流入
- 净流入趋势明显  
- 带长下影收回

## （4）日线沿均线慢慢上行
- 贴着 MA10 或 MA20 缓步上涨

## （5）行业稳定增长
- 半导体设备  
- 光刻机/材料链  
- 国产替代

---

# 2. 判定规则（TRF 自动识别）

```
IF (周线趋势强=True) AND (日线回调浅=True) THEN
    判定 = "华海清科模式（稳健趋势结构）"
```

---

# 3. 输出示例
```
股票C 符合华海模型：趋势稳健 + 回调浅  
→ 建议作为“趋势底仓”观察或配置
```
