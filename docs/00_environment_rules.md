# TRF v2.0 — 环境判定规则（大盘趋势红黄绿灯系统 · 最终格式化版）
版本：v2.1（科技成长主线版）  
适用账户：半导体 / AI 服务器 / 信创安全计算主线账户  
功能定位：作为 **TRF 全体系的风险入口（Risk-Gate）**，约束每日盘前/盘中/盘后策略。

# 📌 0. 文件用途（Why This File Exists）
本文件是 TRF v2.0 的 **环境判定模块**，用于判断当前属于：

- 🟢 **进攻模式**  
- 🟡 **观察模式**  
- 🔴 **防御模式**

所有策略（加仓/减仓/轮动/选股/T+0）必须遵守本规则的优先级：

```
环境判定（红黄绿灯） > 个股趋势信号 > 板块轮动信号 > T+0/临盘判断
```

这是 TRF 风控体系的“最高优先级”。

---

# 🟢 1. 进攻模式（Green Mode）
满足任一指数条件 + 任一板块条件，即进入 **Green**。

## ✔ 指数条件（任一即可）
- 上证指数 ≥ MA20  
- 创业板指数 ≥ MA20  

## ✔ 板块条件（任一即可）
- 半导体指数、AI 服务器或科技 ETF（159995 / 512480）  
  站上 MA20 且持续放量  
- 主线板块出现 3–5 日连续放量上涨

## ✔ 行为策略（你允许进攻的唯一环境）
- 可做突破加仓  
- 可执行轮动换股  
- 可做低吸 + 波段  
- 可做 T 提升胜率  
- GPT 策略选股的命中率最高  
- 仓位建议：**70%–90%**

## ✔ 市场特征
- 强趋势结构稳固  
- 板块联动明显  
- 你的持仓股通常会走加速段

> **这是你最赚钱的环境。**

# 🟡 2. 观察模式（Yellow Mode）
以下出现任意 **2 条** 即进入黄灯：

## ✔ 指数状态
- 指数跌破 MA20（未破 MA60）
- 指数横盘 3–5 日缩量无方向

## ✔ 板块状态
- 半导体 / AI / 信创出现 **3–5 日缩量**  
- 龙头冲高回落但结构未破坏

## ✔ 个股状态
- 持仓仍在 MA20 上方  
- 但 5 日线走平 / 缩量明显

## ✔ 行为策略
- 不能追涨  
- 可以低吸（但必须靠结构）  
- 暂停突破加仓  
- 不做高风险轮动  
- 仓位建议：**50%–70%**

## ✔ 市场特征
- 分化  
- 噪音多  
- 需要等待“右侧信号”

> **这是最容易犯错的环境（你 70% 的亏损来自黄灯）。**

---

# 🔴 3. 防御模式（Red Mode）
以下出现 **任意 1 条** 即进入红灯：

## ✔ 指数状态
- 上证/创业板 **放量跌破 MA20**  
- 连续跌破 **MA20 + MA60**

## ✔ 板块状态
- 半导体 / AI / 信创出现 **放量长阴**  
- 龙头集体杀跌（3–5 只跌超 6%）

## ✔ 个股状态
- 主仓（如 NAURA）放量跌破 MA20  
- 任何持仓出现放量长阴破平台

## ✔ 行为策略
- 禁止加仓  
- 禁止追涨  
- 减仓为主  
- 不进行轮动  
- 弱势票不恋战  
- 仓位建议：**30%–50%**

## ✔ 市场特征
- 系统性杀跌  
- 高低不分  
- 单靠个股不可能抗跌

> **红灯 = 必须防守，不做进攻动作。**

# 🎛 4. 环境 → 日常策略影响（强制执行）
每日我给你的策略，会按以下三个模式自动切换：

| 模式 | 你将收到的策略内容 | 策略风格 |
|------|---------------------|-----------|
| 🟢 Green | 突破点、加仓点、轮动、T+0、主线评分 | 进攻 |
| 🟡 Yellow | 控仓、低吸、严格选股、短线止盈 | 中性 |
| 🔴 Red | 减仓、风控提示、禁止加仓、不做新票 | 防御 |

**无论什么模式，我都会给你“可执行方案”，不是简单地让你等待。**

# ⚖ 5. 系统优先级（写入内核的重要规则）
环境判定信号的级别高于一切：

```
红/黄/绿灯 > 个股趋势 > 板块轮动 > 临盘判断
```

说明：

- 即使个股很强，但市场是黄灯 → 不能加仓  
- 即使出现突破，但市场是红灯 → 禁止追  
- 强势票可以持有，但不能“提升仓位”  
- 任何违反三色灯的行为都会增加亏损概率  

> **只有“绿灯 + 你的成功模式结构” 才允许大仓位出手。**

# 🧭 6. 实盘流程联动（与 Daily-Playbook 一致）

### ✔ 收盘（前一天）  
- 你给我持仓图  
- 我根据三色灯做 **次日攻击/防御策略**

### ✔ 盘前（可选）  
- 若你发指数/板块截图，我更新当日灯号  
- 若不发 → 我按昨收策略执行

### ✔ 上午 10:30  
- 检查绿灯是否失效  
- 检查是否出现假突破/分歧

### ✔ 中午 11:30  
- 判断是否从绿灯 → 黄灯  
- 判断是否要下午减仓或等待二次机会

### ✔ 下午 13:45  
- 判断是否从黄灯 → 红灯  
- 判断是否要尾盘减仓

### ✔ 收盘  
- 回到下一轮 Day-Playbook
