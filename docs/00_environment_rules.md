# TRF v2.0 — 环境判定规则（大盘趋势红绿灯系统）
版本：v2.0（半导体方向）  
适用账户：科技成长主线账户（半导体 / AI 服务器 / 信创安全计算）

---

# 🎯 规则目的
本规则用于判断当前市场处于 **进攻模式 / 观察模式 / 防御模式**，作为每日实盘策略的基础框架。

TRF v2.0 所有操作（加仓 / 减仓 / 换股 / 选股有效性）必须参考本规则。

---

# 🟢 一、进攻模式（绿灯）
**满足任一指数条件即可：**
- 上证指数 ≥ 20 日均线  
- 创业板指数 ≥ 20 日均线  

**板块条件（满足任一项即可）：**
- 半导体指数 / 科技 ETF（如 159995、512480）站上 20 日线  
- 主线板块出现 3–5 日持续放量

### ✔ 行为策略  
- 允许做突破加仓  
- 可做低吸 + 波段  
- 可做 T+0 提升胜率  
- 策略选股（盘后）命中率高  
- 盘中二次筛选（10:30 / 13:45）准确度高  
- 仓位建议：**70%–90%**

### ✔ 特点  
- 个股顺势最容易产生趋势行情  
- 你持仓的强势票会加速  
- TRF 模型的“趋势 + 轮动”部分最有效

---

# 🟡 二、观察模式（黄灯）
**指数状态：**
- 跌破 20 日线，但 **仍在 60 日线上方**

### ✔ 行为策略  
- 不能追涨  
- 强势票继续做  
- 以回踩低吸为主  
- 选股更严格（缩量票不碰）  
- 盘中策略减少高频干预  
- 仓位建议：**50%–70%**

### ✔ 特点  
- 市场处于震荡市  
- 个股分化明显  
- 有些强势票仍可走出独立行情（例如：侨源 / 川仪 这种结构票）

---

# 🔴 三、防御模式（红灯）
**满足以下任一：**
- 指数跌破 20 日线 + 60 日线  
- 主线板块（半导体、AI）持续缩量 5–7 日  
- 外围重大利空导致恐慌跳水

### ✔ 行为策略  
- 禁止追涨  
- 新标的仅观察，不参与  
- 优先减仓止盈  
- 强势票保留底仓，不做加仓  
- 弱势票不恋战  
- 仓位建议：**30%–50%**

### ✔ 特点  
- 系统性风险升高  
- 即使是强势票也容易发生“无差别杀跌”  
- 此时必须守住本金，等待下一轮趋势窗口

---

# 🎛 四、模式切换对每日策略的影响
每日盘前、盘中、盘后我给出的策略信号都将受到“红绿灯系统”控制：

| 指标状态 | 我提供的策略内容 | 策略风格 |
|---------|------------------|----------|
| 🟢 绿灯 | 完整加仓点、突破点、轮动提示、T+0 节奏 | 进攻 |
| 🟡 黄灯 | 控仓、回踩买点、谨慎突破、快节奏止盈 | 中性 |
| 🔴 红灯 | 减仓、风险提示、禁止追涨、不做新票 | 防御 |

**无论何种模式，我都会提供“明确操作策略”，不是停止策略。**

---

# 🧭 五、关键原则（写入系统）
```
不逆大趋势做满仓交易。
不在红灯状态做激进操作。
不在黄灯状态追高。
进攻窗口出现必须迅速执行。
```

---

# 📌 六、与实盘结合（非常重要）
在你的每日流程中：

- 盘后给我持仓截图 → 我根据此规则给你第二天策略  
- 上午 10:30 截图 → 检查是否符合绿灯的盘中状态  
- 中午 11:30 截图 → 评估格局是否恶化  
- 下午 13:45 截图 → 判断是否进入加速 or 转弱  
- 收盘后 → 次日策略生成

所有判断，均将在本规则下执行。
