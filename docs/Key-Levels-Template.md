# Key-Levels-Template — 个股关键位模板（TRF v2.0）

> 本文件是 **模板**，不是针对某一只股票的实盘记录。  
> 每当一只股票被纳入 TRF 体系重点跟踪时，都应按本模板单独建档。

---

## 0. 使用说明（How to Use）

- 本模板用于记录每只重点个股的：
  - 角色定位（Core / Attack / Defensive / Test）
  - 所属主线 / 子主线
  - 当前所处区间（低位 / 中位 / 高位）
  - 关键支撑位 / 防守位 / 攻击位 / 止盈区间
  - 简短策略说明（适配你的风格）

- 实际使用方式：
  1. 复制本模板，重命名为 `Key-Levels-<Ticker>.md`  
     例如：`Key-Levels-002371-NAURA.md`
  2. 将尖括号（`<>`）中的内容替换为实际信息
  3. 收盘后或结构有变化时，适当更新关键价位与文字说明

## 3. 关键价位表（Key Levels Table）

> 所有价格均以 **收盘后** 为准，由 AI 根据当日图形 + 你的截图共同确定。

### 3.1 表格版（推荐）

| 类型 | 符号 | 价格区间（¥） | 含义说明 | 行动建议（默认条件：Green / Yellow 环境） |
|------|------|---------------|----------|-------------------------------------------|
| 支撑位1 | S1 | `<X1>` | 最近有效的强支撑，跌破会削弱多头趋势 | 绿灯：可考虑低吸；黄灯：仅小仓试探 |
| 支撑位2 | S2 | `<X2>` | 更深一档支撑，多为空头洗盘极限 | 跌破需审视逻辑是否破坏 |
| 防守位 | D  | `<Xd>` | 跌破视为本轮趋势大概率结束 | 一般应减仓或止损；不再加仓 |
| 攻击位1 | A1 | `<Xa1>` | 首个关键压力 / 前高位置 | 放量突破可考虑加仓 or 启动首仓 |
| 攻击位2 | A2 | `<Xa2>` | 更高一级压力，多为前高或平台上沿 | 强势突破进入加速段，可部分追击 |
| 止盈区间1 | TP1 | `<T1_low> - <T1_high>` | 本轮保守止盈区间 | 到达后建议分批锁定 20%–30% 仓位 |
| 止盈区间2 | TP2 | `<T2_low> - <T2_high>` | 乐观目标区间 | 到达后视市场环境与结构分批兑现 |

> 注：  
> - S1 / S2 / D 通常参考 MA20 / MA60 / 前低 / 形态支撑区间综合得出。  
> - A1 / A2 通常参考前高 / 缺口 / 平台上沿。  
> - TP1 / TP2 需结合历史波动空间与板块空间估算。

## 4. 结构 + 关键位的文字策略（Strategy Notes）

### 4.1 标准策略句式参考（可直接套用）

- **低吸条件（靠近支撑位）**  
  - 当股价回踩到 `S1 = <X1>` 附近，  
    - 且大盘处于 `<Green / Yellow>`，  
    - 且量能缩量、无放量长阴，  
    → 视为健康回踩，可按计划低吸 `<仓位比例>`。  

- **止损 / 防守动作**  
  - 若股价 **放量跌破 D = <Xd>**，  
    - 视为本轮趋势大概率结束，  
    → 应减仓 `<比例>` 或清仓，禁止继续补仓摊成本。  

- **突破加仓条件（靠近攻击位）**  
  - 当股价放量突破 `A1 = <Xa1>`，  
    - 且分时在 `10:30 / 13:45` 出现二次放量结构，  
    → 可将仓位从 `<原仓位>` 提升至 `<目标仓位>`。  

- **止盈动作（到达 TP 区间）**  
  - 当股价进入 `TP1 = <T1_low>–<T1_high>` 区间，  
    → 分批兑现 20%–30% 仓位；  
  - 若力度继续强劲并进入 `TP2 = <T2_low>–<T2_high>`，  
    → 再分批兑现 30%–40% 仓位，保留尾仓跟随趋势。
