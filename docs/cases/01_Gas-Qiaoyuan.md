# 1. 背景：侨源为什么能成为强势案例？

侨源科技属于 **科技制造业的关键耗材/零部件类公司**，典型特点：

- 下游需求来自：半导体、工业控制、特气、设备制造  
- 具备一定“硬科技+工业底座”属性  
- 小市值、弹性高、趋势一旦启动非常迅猛  
- 容易成为 **资金寻找补涨方向的首选**

侨源的主升启动力度高，是你在 TRF 系统下捕捉到的 **“进攻轮动仓” 模式的最佳范例**。

侨源的上涨不是偶然，而是：

> **低位 + 放量 + 板块轮动 + 结构加速 + 资金主导**  
> 共同形成的“加速爆发模型”。

# 2. TRF 三维识别（Trend / Rotation / Flow）

## 🔷 2.1 Trend（趋势）

侨源的趋势信号非常标准：

1. **长期横盘→低位吸筹明显（均线密集缠绕）**
2. **突破 MA20 → 再突破 MA60 → 双突破确立趋势**
3. **中阳突破前高，量价关系健康**
4. **均线形成多头排列：MA5 > MA10 > MA20**

典型的：

> **右侧趋势反转 + 主升浪第一阶段（启动段）**

这类结构就是 TRF 体系最擅长捕捉的模式之一。

---

## 🔷 2.2 Rotation（轮动）

侨源的核心是一句话：

> **它是科技主线内部“轮动第二棒”的典型票。**

当时的结构是：

- 北方华创等设备龙头震荡  
- 半导体材料 / 耗材开始放量  
- 工控仪表、设备零部件方向走强  
- 你同时关注的川仪、中科星图等方向同步出现加速

侨源属于：

**从设备龙头 → 材料/耗材细分 → 轮动加速的核心标的。**

这完全符合 TRF 的轮动逻辑：

- 龙头震荡  
- 次龙头补涨  
- 低位方向放量突破  
- 板块 ETF 同步回暖  
- GPT 盘后策略池连续出现材料类股票  

→ 轮动确认。

---

## 🔷 2.3 Flow（资金）

侨源的资金结构非常典型：

1. **初启阶段：放量上攻突破 MA60**  
   - 真实资金介入  
   - 形态干净、无杂波

2. **二次加速：突破前高并放量 1.5–2 倍**  
   - 关键攻击点（你抓对了）

3. **回踩阶段：缩量、实体短、下影明显**  
   - 洗盘属于健康结构

4. **再加速：连阳 + 放量**  
   - 进入主升浪加速区间

侨源的 Flow 特征是：

> **“堆量 + 突破 + 再堆量” → 属于加速型结构，而不是震荡型结构**

这类票在 TRF 轮动体系中属于 **高弹性进攻票**。

# 4. 侨源模式（未来如何复刻）

侨源的模式属于：

> **低位 → 放量突破 → 回踩确认 → 加速 → 主升浪第一段**

以下是未来识别“侨源模式”的 checklist：

### ✔ ① 是否长期横盘 + 均线粘合？
（代表低位筹码稳定）

### ✔ ② 是否第一次放量突破 MA60？
（右侧趋势开始）

### ✔ ③ 是否大阳突破前高？
（进攻信号）

### ✔ ④ 是否出现缩量回踩？
（洗盘确认）

### ✔ ⑤ 是否二次放量突破？
（主升浪开始）

### ✔ ⑥ 是否属于科技主线中的细分补涨方向？
（低位补涨弹性最大）

满足 4 条 → 小仓  
满足 5 条 → 进攻仓  
满足 6 条 → 目标抓主升浪

→ 这就是你抓住侨源的完整逻辑。
