# 🔥 三大成功案例模型化总结

本目录的三个案例分别代表 TRF 系统的三个核心赚钱模式：

---

## ① 阳光电源（Solar Model）  
**模型类型：主升浪龙头 / 右侧反转型**

- MA20→MA60 双突破  
- 右侧放量反转  
- 攻击波 → 回踩 → 主升浪  
- 属于科技成长中的 **绝对龙头**

📌 适用角色：  
**Core Leader（核心龙头仓）**

📌 核心特点：  
趋势稳定、空间大、持续性强

---

## ② 侨源科技（QYA Model）  
**模型类型：科技补涨 / 加速突破型**

- 低位长时间盘整  
- 首次放量突破 MA60（趋势起点）  
- 回踩确认 + 二次放量加速  
- 属科技主线的 **第二棒 / 补涨方向**

📌 适用角色：  
**Aggressive Rotation（进攻仓）**

📌 核心特点：  
弹性强、启动快、吃 3–10 日加速段

---

## ③ 北方稀土（Rare Earth Model）  
**模型类型：政策驱动 / 资源主线型**

- 强政策明确催化  
- 行业高集中度 + 龙头唯一性  
- 板块资金 3 天以上净流入  
- 趋势 + 板块 + 资金 → 共振

📌 适用角色：  
**Core Leader（周期主线龙头）**

📌 核心特点：  
确定性高、政策周期强、适合作为某阶段重仓品种

---

# 📌 模型之间的差异（非常重要）

| 模型 | 方向/属性 | 仓位角色 | 启动方式 | 空间 | 可复刻性 |
|------|-----------|-----------|-----------|--------|------------|
| **阳光电源** | 科技反转龙头 | Core Leader | 右侧反转 + 主升 | 中高 | 中等偏高 |
| **侨源科技** | 科技补涨加速 | Attack | 低位放量 + 加速 | 高 | 最高 |
| **北方稀土** | 资源政策龙头 | Core Leader | 政策驱动 + 板块共振 | 中等 | 依政策 |

---

# 📌 三大模型对应的 TRF 维度

| TRF 维度 | 阳光电源（Solar） | 侨源（QYA） | 北方稀土（RareEarth） |
|---------|---------------------|--------------|------------------------|
| Trend（趋势） | 右侧反转 + 多头结构最强 | 低位趋势反转 | 政策型趋势确认 |
| Rotation（轮动） | 科技主线内部核心方向 | 科技主线补涨方向 | 市场资金大切换 |
| Flow（资金） | 稳定堆量 + 持续主升 | 加速型堆量突破 | 板块净流入最强 |
