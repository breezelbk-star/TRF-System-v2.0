# 北方稀土案例：TRF 如何识别“科技以外的短期主线”（Rare Earth Case Study）

> 本案例属于“应用层”，用于说明 TRF 如何识别主线，不会影响内核规则。
> 通过该案例，可以学习 TRF 如何处理政策型主线、资源型主线、跨行业主线。

---

# 📌 1. 背景：北方稀土为何突然变成主线？

尽管本账户长期主线在 **科技成长方向（半导体、AI、信创等）**，  
但市场的资金主线 **并不永远是科技**。

北方稀土属于 **资源+政策+强供需周期** 的典型案例，符合 TRF 主线识别逻辑：

### ✔ 1) 国家政策密集催化  
- 稀土出口政策收紧  
- 下游永磁体需求提升  
- 国家层面推动战略资源保供  
→ 这些信息构成 **政策型主线催化**。

### ✔ 2) 行业集中度极高（龙头唯一性）  
- 北方稀土属于 **稀土行业绝对龙头（CR5 > 85%）**  
- 龙头地位明确、资金更容易集中  
→ 满足 TRF 的【龙头核心仓（Core Leader）】标准。

### ✔ 3) 板块资金毫无疑问的集中流入  
- 行业内出现 “板块同时放量”  
- 北方稀土走最强  
→ 满足 TRF 的【Rotation：资金集中度决定主线】规则。

### ✔ 4) 技术面进入主升浪初期  
- 站上 20/60 日线  
- 放量突破前高  
- 回踩确认后量能再次放大  
→ 完整符合 TRF 的【Trend】条件。

# 🧩 2. TRF 三维框架识别过程（完整还原）

以下复现 TRF（Trend / Rotation / Flow）三维同时成立的画面：

---

## 🔷 2.1 Trend（趋势）  
### **大盘趋势：偏中性或偏防御时**  
科技主线疲软 → 资金寻找“确定性更高的方向”。  
这时 **资源类、国企类、稳需求类** 更容易被资金当作“避风港”。

### **行业趋势：稀土 ETF 站上 20 日线并放量**  
趋势从弱 → 强，开启第一波攻击。

### **个股趋势：北方稀土形态完美具备三要素**  
- MA5 > MA10 > MA20 → 多头结构  
- MA20 上拐 → 趋势转强  
- 放量突破 → 真突破  
- 回踩 MA10/20 → 健康洗盘  
→ 典型的“主升浪前段结构”。

---

## 🔷 2.2 Rotation（轮动）  
主线科技暂时疲软 → TRF 自动启动「可变风口」模块。

稀土方向当时满足：

- 新增资金持续 3 天流入  
- 板块龙头（北方稀土）率先突破  
- 下游永磁体、钕铁硼同步起势  
- 策略选股池连续出现同类标的  
→ 形成 TRF 判定的 **轮动确认信号**。

这与 TRF 的轮动原则完全一致：

> **主线不是固定行业，由增量资金决定。  
> 资金在哪儿，主线就在哪儿。**

---

## 🔷 2.3 Flow（资金）  
北方稀土当时出现典型“超级主线票”的资金形态：

### ✔ 第一波：突破放量  
- 量比 >1.8  
- 金额放大明显  
- 实体中阳  
→ 资金开始攻击。

### ✔ 第二波：回踩缩量 + 转强放量  
- 回踩 MA10/20 缩量  
- 随后再次放量并收强阳  
→ 资金确认“洗盘完成”。

### ✔ 第三波：板块联动放量  
- 板块 ETF 放量  
- 行业内多股涨停或高涨幅  
→ 主升浪进入“扩散期”。

**Flow（资金）三步齐全 → 主线确定。**

# 📌 3. 品种定位：北方稀土在 TRF 体系中属于什么角色？

在 TRF 的四类仓位体系中：

```
Core（核心龙头）  
Attack（进攻轮动）  
Defensive（防御）  
Test（试错）
```

北方稀土属于：

# ⭐ **Core Leader（核心龙头仓）**
理由：

- 板块绝对龙头  
- 行业确定性强  
- 政策催化持续性强  
- 资金集中度最高  
- 趋势形态完美健康  
- 风险收益比优秀  

当科技主线弱，而资源主线强 →  
它就是“当前周期最值得重仓的品种”。

# 📌 4. 未来如何复刻北方稀土模式？

这是你最需要的部分。

当未来遇到“科技主线不稳 + 某板块突然连续放量”时  
你可以套用这份 checklist：

## ✔ ① 是否具备明确政策逻辑？  
如国家资源、安全、外贸、科技替代等。

## ✔ ② 是否行业龙头最强？  
非龙头不做主升浪。

## ✔ ③ 是否板块持续 3 天净流入？  
三天法则很关键。

## ✔ ④ 是否日线突破 + 回踩确认？  
避免假突破。

## ✔ ⑤ 是否具备扩散性？  
（即：同行个股也跟涨）

## ✔ ⑥ 是否具有“市场情绪避风港属性”？  
比如关税风险 + 科技冲击 → 资金更爱资源/能源。

满足 4/6 → TRF 允许纳入主线。

满足 5/6 → TRF 允许重仓。

满足 6/6 → TRF 允许进入 **龙头核心仓（Core）**。
