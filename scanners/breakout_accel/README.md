# 📌 4. 信号结构（7 大过滤器）

### **① 趋势过滤（Trend）**  
- C>MA60  
- MA20>MA60  
- 5>10>20 斜率  
→ 只做右侧上涨，不做左侧反弹。

### **② 接近突破（Near Break）**  
- C ≥ 20 日高点的 98%  
- 或当日盘中接近前高  
→ 只抓突破，不做震荡。

### **③ 量能模型（Flow）**  
**侨源模式（PULSE）**：脉冲型爆量  
**川仪模式（STACK）**：均线堆量持续  
→ 只要有“主力堆量痕迹”就能抓到。

### **④ 情绪过滤（Hot Control）**  
- KDJ.K < 88  
- 不大幅跳空  
→ 避免追到情绪票和假突破。

### **⑤ 流动性过滤（Liquidity）**  
- 金额 ≥ 2 亿  
- 上市 ≥ 120 天  
→ 保证能交易、能进能出。

### **⑥ 价格过滤（Price Range）**  
- 股价 6～200 元  
→ 完全符合科技主线风格。

### **⑦ 最终信号（XG）**  
全部条件通过 → 才触发信号。
