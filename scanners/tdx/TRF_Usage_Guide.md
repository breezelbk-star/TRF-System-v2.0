# TRF v2.0 Scanners｜使用说明（L1 + L2）

## 1. 各指标定位

- TRF_L1_Pool_BreakoutMomentum
  - 角色：一级候选池（进池）
  - 目标：不漏“可能启动”的票
  - 特征：允许误报、数量多是正常的
  - 禁止：看到 L1 信号就直接重仓

- TRF_L2_Rebound_2ndWave
  - 角色：二波反包确认（主仓买点/加仓点）
  - 目标：从候选池中找“最优上车点”
  - 适用：长光型、侨源二段型、趋势确认后的二次启动

## 2. 收盘后标准流程（10–20 分钟）

1) 跑 L1：得到一级候选池
2) 对候选池做人工 Case 归类（像侨源/像长光）
3) 对“像长光/侨源二段”的票跑 L2
4) L2 出信号 → 进入次日执行计划（挂单/分批/止损）

## 3. 操作铁律

- L1 = 探照灯，不是扳机
- L2 = 扳机，但也要先完成 Case 归类
- 任何无法归类的票：不交易

## 4. 典型对应

- 长光 11/6：属于点火（不一定被 L2 捕捉）→ L1 能入池即可
- 长光 11/25：典型二波反包 → L2 应该能捕捉
- 侨源：点火即突破 → L1 入池；若出现二段回踩反包，L2 会给加仓点
